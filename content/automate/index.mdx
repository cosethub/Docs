## Mental model (one paragraph)

Store connections once in **Credential Hub**. Build a **workflow tree** (Group + child jobs) that a **Bridge** executes on a schedule or parent status (**On success** / **On failure** / **Always**). Jobs land files in a **file store** and/or rows in a **warehouse**. **Views** shape tables; **data monitors** alert on bad rows; **checklists** bind jobs and monitors to a **period calendar**. The **Public API** runs the same jobs and reads the same warehouses the UI uses.

## Agent / integrator checklist

1. Confirm tenant URL and that a **Bridge** is online.
2. Create or reuse a **credential** for the counterparty (SFTP, IMAP, SQL, Geneva, Bloomberg, …).
3. Create a **Group** workflow named for the business process.
4. Add jobs; map upstream **outputs** into downstream **inputs** (do not hard-code landed paths).
5. Wire **On failure** Email (or escalation) for ops visibility.
6. For period close, attach the milestone job (and monitors) to a **checklist**.
7. For external schedulers, use OAuth or a job API key and `POST /jobs/:jobId/run`.
