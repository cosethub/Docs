# File stores

Browse, download, upload, and manage file store objects.

> **Base:** `/api/v1`  
> **Auth:** `Authorization: Bearer {token}`  
> **Scopes:** `file-stores:read` / `file-stores:write`  
> **Legacy prefix:** `/api/file-store/stores`

---

## Endpoints

| Method | Path | Action |
| --- | --- | --- |

| `GET` | [`/file-stores/{storeId}/items`](#get-file-storesstoreiditems) | List folder |
| `GET` | [`/file-stores/{storeId}/download-url`](#get-file-storesstoreiddownload-url) | Presigned URL |
| `GET` | [`/file-stores/{storeId}/settings`](#get-file-storesstoreidsettings) | Settings |
| `POST` | [`/file-stores`](#post-file-stores) | Create store |

| `POST` | [`/file-stores/{storeId}/upload`](#post-file-storesstoreidupload) | Multipart upload |

## Shared types

### `FileStore`

| Field | Type | Description |
| --- | --- | --- |
| `id` | `integer` / `string` | Store ID |
| `user_defined_name` | `string` | Display name |
| `bucket_name` | `string` | Underlying bucket |
| `description` | `string \| null` | |
| `default_folder_path` | `string \| null` | Default browse path |
| `is_default` | `boolean` | Org default store |
| `store_type` | `string` | e.g. `FileStore` |
| `permissions` | `PermissionRule[]` | Access rules |

### `FileStoreItem`

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | File or folder name |
| `path` | `string` | Full path within store |
| `is_folder` | `boolean` | |
| `file_count` | `integer` | For folders |
| `size_bytes` | `integer \| null` | For files |
| `description` | `string \| null` | |
| `created_by` | `string \| null` | |
| `created_utc` | `string` | ISO 8601 |

### `PermissionRule`

| Field | Type | Description |
| --- | --- | --- |
| `principal_type` | `string` | `user`, `group`, `role` |
| `principal_id` | `integer` / `string` | |
| `access` | `string` | `read`, `write`, `admin` |

## Read

### `GET /file-stores`

List stores for the organization.

| | |
| --- | --- |
| **Status** | Planned (today: `GET /api/file-store/stores`) |
| **Scopes** | `file-stores:read` |

#### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `store_type` | `string` | `FileStore` | Filter by store type |

#### Response `200 OK`

```json
{
  "stores": [
    {
      "id": 3,
      "user_defined_name": "Ops Files",
      "bucket_name": "acme-ops-files",
      "description": "Daily drops",
      "default_folder_path": "inbound/",
      "is_default": true,
      "store_type": "FileStore",
      "permissions": []
    }
  ]
}
```

> Legacy returns a raw array of store DTOs (PascalCase). v1 wraps as `{ stores: […] }` with snake_case.

```bash
curl -sS -H "Authorization: Bearer $ACCESS_TOKEN" \
  "https://{tenant}.cosethub.com/api/v1/file-stores?store_type=FileStore"
```

### `GET /file-stores/{storeId}/download-url`

| | |
| --- | --- |
| **Status** | Planned (today: `GET /api/file-store/stores/{storeId}/download-url`) |
| **Scopes** | `file-stores:read` |

#### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `path` | `string` | Yes | Full file path |

#### Response `200 OK`

```json
{
  "url": "https://…presigned…",
  "expires_at": "2026-07-11T17:00:00Z"
}
```

> Legacy: `{ "Url": "…" }` only. v1 adds snake_case `url` and optional `expires_at`.

```bash
curl -sS -G \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  --data-urlencode "path=inbound/positions.csv" \
  "https://{tenant}.cosethub.com/api/v1/file-stores/3/download-url"
```

## Write

### `POST /file-stores`

Create a store.

| | |
| --- | --- |
| **Status** | Planned (today: `POST /api/file-store/stores`) |
| **Scopes** | `file-stores:write` |

#### Request body

```json
{
  "user_defined_name": "Research Drop",
  "description": "Vendor research files",
  "is_default": false,
  "store_type": "FileStore",
  "default_folder_path": "",
  "permissions": []
}
```

#### Response `201 Created`

```json
{
  "id": 9,
  "user_defined_name": "Research Drop",
  "bucket_name": "acme-research-drop",
  "description": "Vendor research files",
  "default_folder_path": "",
  "is_default": false,
  "store_type": "FileStore",
  "permissions": []
}
```

> Legacy may return `200` with empty body after create. v1 returns the created store.

### `POST /file-stores/{storeId}/upload`

Multipart file upload into a folder path.

| | |
| --- | --- |
| **Status** | Planned (today: `POST /api/file-store/stores/{storeId}/upload`) |
| **Scopes** | `file-stores:write` |
| **Content-Type** | `multipart/form-data` |

#### Form fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `path` | `string` | No | Destination folder |
| `file` | `file` | Yes | One or more files (`file`, `file[]`, or multiple parts) |

#### Response `200 OK`

Empty body on success.

```bash
curl -sS -X POST \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -F "path=inbound/july/" \
  -F "file=@./positions.csv" \
  "https://{tenant}.cosethub.com/api/v1/file-stores/3/upload"
```

### `PUT /file-stores/{storeId}/objects`

Upload or replace a single object at an exact path (normalized put).

| | |
| --- | --- |
| **Status** | Planned (normalize upload) |
| **Scopes** | `file-stores:write` |

Supports either:

1. **JSON** with base64 body (small files), or  
2. **multipart** with `path` + `file`

#### JSON request

```json
{
  "path": "inbound/july/positions.csv",
  "content_base64": "U3ltYm9sLFByaWNlCg==",
  "content_type": "text/csv",
  "description": "EOD positions"
}
```

#### Response `200 OK`

```json
{
  "path": "inbound/july/positions.csv",
  "size_bytes": 14,
  "content_type": "text/csv"
}
```
