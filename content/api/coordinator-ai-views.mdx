# Coordinator & AI views

Optional v1 surfaces for the Coordinator agent and AI View Assistant.

> **Base:** `/api/v1`  
> **Auth:** `Authorization: Bearer {token}`  
> **Status:** **Exists** under legacy prefixes (listed per endpoint)  
> These endpoints are session-oriented and may stream.

---

### `POST /coordinator/chats/{chatId}/messages`

Send a message (non-stream or buffered response).

| | |
| --- | --- |
| **Status** | **Exists** — `POST /api/coordinator-chats/{chatId}` (legacy posts to chat root) |
| **Scopes** | `coordinator:write` |

#### Request body

```json
{
  "message": "Create a credential for our vendor SFTP and a download job."
}
```

#### Response `200 OK`

```json
{
  "assistant_message": "…",
  "plan": { },
  "actions": []
}
```

> Response shape is assistant-defined and may include plan panes, credential wizards, or action proposals. Treat unknown fields as additive.

v1 path uses `/messages` for clarity; legacy posts to `POST /api/coordinator-chats/{chatId}`.

### `POST /coordinator/chats/{chatId}/messages` (stream)

Stream assistant tokens / events.

| | |
| --- | --- |
| **Status** | **Exists** — `POST /api/coordinator-chats/{chatId}/stream` |
| **Scopes** | `coordinator:write` |
| **Accept** | Prefer `text/event-stream` |

#### Request body

Same as non-stream message request.

#### Response `200 OK` — SSE

```
event: token
data: {"text":"I'll"}

event: token
data: {"text":" help"}

event: done
data: {"chat_id":"c0ffee00-…"}
```

Exact event names may vary; clients should ignore unknown events.

```bash
curl -N -X POST \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Accept: text/event-stream" \
  -d '{"message":"List my warehouses"}' \
  "https://{tenant}.ryanplatform.com/api/v1/coordinator/chats/$CHAT_ID/messages?stream=true"
```

Legacy stream URL: `POST /api/coordinator-chats/{chatId}/stream`.

## Schema index (AI)

Index warehouse tables so the assistant can reason about schema.

Legacy prefix: `/api/warehouses/{warehouseId}/schema-index`

### `POST /warehouses/{warehouseId}/schema-index`

Index one or more tables for AI retrieval.

| | |
| --- | --- |
| **Status** | **Exists** |
| **Scopes** | `ai-views:write` |

#### Request body

```json
{
  "table_name": "dbo.Positions"
}
```

or

```json
{
  "table_names": ["dbo.Positions", "dbo.Prices"]
}
```

#### Response `200 OK`

```json
{
  "indexed": ["dbo.Positions"],
  "status": "ready"
}
```

---

### `DELETE /warehouses/{warehouseId}/schema-index/{tableName}`

Remove a table from the AI schema index.

| | |
| --- | --- |
| **Status** | **Exists** |
| **Scopes** | `ai-views:write` |

#### Path parameters

| Name | Type | Description |
| --- | --- | --- |
| `tableName` | `string` | URL-encoded table name |

#### Response `200 OK` / `204 No Content`

```bash
curl -sS -X DELETE \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  "https://{tenant}.ryanplatform.com/api/v1/warehouses/7/schema-index/dbo.Positions"
```
