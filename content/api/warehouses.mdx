# Warehouses

Read and write warehouse metadata, schemas, rows, exports, and view definitions.

> **Base:** `/api/v1`  
> **Auth:** `Authorization: Bearer {token}`  
> **Scopes:** `warehouses:read` / `warehouses:write`

Today, many warehouse operations go through ProcessServer websockets. Public REST wraps those ops under `/warehouses/*`.

### `TableSummary`

| Field | Type | Description |
| --- | --- | --- |

| `display_name` | `string \| null` | UI label |
| `row_count` | `integer \| null` | Approximate count when known |
| `has_screen_access` | `boolean` | Caller can see this table |

### `ViewSummary`

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | View name |
| `schema` | `string \| null` | Schema |
| `description` | `string \| null` | |

### `ViewDefinition`

The warehouse **Views** tab saves this object. `POST` and `PUT` take it as the body. `GET` returns it. Property names are PascalCase.

| Field | Type | Description |
| --- | --- | --- |
| `Schema` | `string` | Letters, digits, and underscores. Must start with a letter or underscore. Often `ref` |
| `Name` | `string` | Same character rules as `Schema` |
| `Description` | `string \| null` | Omitted on `PUT` clears it |
| `Table` | `string` | Schema-qualified base table, for example `ref.book_positions`. Omitted on `PUT` clears it |
| `JoinCriteria` | `JoinCriteria[]` | Optional related tables. Use `[]` when there is no join |
| `GroupByColumns` | `GroupByColumn[]` | Use `[]` when every matching row stays visible. Fill this to roll rows up |
| `SelectColumns` | `SelectColumn[]` | At least one. Array order is output order |
| `Where` | `WhereGroup \| null` | Optional row filter |

`Schema` and `Name` on a `PUT` must match the path. The saved spelling is kept. Roles, owners, and tags sent on `PUT` are ignored. The saved ones stay.

`GET` also returns `Id`, `OrganizationId`, `WarehouseId`, `IsEnabled`, `Tags`, `WarehouseViewRoles`, and `OwnerIds`.

### `JoinCriteria`

| Field | Type | Description |
| --- | --- | --- |
| `Table1` | `string` | Schema-qualified left table |
| `Table2` | `string` | Schema-qualified table being brought in |
| `JoinType` | `string` | `INNER`, `LEFT`, `RIGHT`, or `FULL` |
| `Children` | `array` | Match conditions. Each item is a `JoinCondition`, or a group with `"Type": "group"` and its own `Children` |

### `JoinCondition`

| Field | Type | Description |
| --- | --- | --- |
| `Type` | `string` | `condition` |
| `LeadingLogicalOperator` | `string \| null` | `AND` or `OR`. Omit on the first child |
| `Source1` | `object` | `{ "Column": "schema.table.column" }` |
| `Operator` | `string` | Usually `=` |
| `Source2` | `object` | Same shape as `Source1` |
| `CastToDate` | `boolean` | Compare the date and ignore time |

### `GroupByColumn`

| Field | Type | Description |
| --- | --- | --- |
| `Table` | `string` | Schema-qualified source table |
| `Column` | `string` | Category column |

### `SelectColumn`

| Field | Type | Description |
| --- | --- | --- |
| `Type` | `string` | `Reference`, `Calculated`, `SUM`, `COUNT`, `AVG`, `MIN`, `MAX`, `Conditional`, or `Coalesce` |
| `DisplayName` | `string` | Unique in the view. Same character rules as `Name` |
| `Source` | `object` | `Reference`, and an aggregate over one column. `{ "Table": "schema.table", "ColumnConfig": { "ColumnName": "Column" } }` |
| `Calculation` | `string` | `Calculated`, `Conditional`, and `Coalesce`. A JSON string, not an object |
| `IsDistinct` | `boolean` | `SUM`, `COUNT`, and `AVG` only. Default `false`. Not valid on `COUNT(*)` |
| `InnerType` | `string` | Aggregates only. `Column`, `Calculated`, or `Conditional` |

`SUM`, `AVG`, `MIN`, and `MAX` need `GroupByColumns`. `COUNT(*)` is `Type` `COUNT` with no `Source`.

A calculated `Calculation` string is a group. The first child has no `LeadingOperator`. The next child sets `LeadingOperator` to `+`, `-`, `*`, `/`, or `^`. A value node has `Type` `value` and `Value.Column` set to `schema.table.column`, or `Value.Column` `__custom` with `CustomValue`.

### `WhereGroup`

| Field | Type | Description |
| --- | --- | --- |
| `Type` | `string` | `group` |
| `Children` | `array` | Each item is a `WhereCondition` or a nested group |

### `WhereCondition`

| Field | Type | Description |
| --- | --- | --- |
| `Type` | `string` | `condition` |
| `LeadingLogicalOperator` | `string \| null` | `AND` or `OR`. Omit on the first child |
| `LeftValue` | `object` | `{ "Column": "schema.table.column" }`. A source column, not a `DisplayName` |
| `Operator` | `string` | See below |
| `RightValue` | `object` | A source column, or `{ "Column": "__custom", "CustomValue": ... }`. Omit for `is null` and `is not null` |
| `RightStartDate` | `string` | Date `between` only |
| `RightEndDate` | `string` | Date `between` only |

| Left side | Operators |
| --- | --- |
| Number, boolean | `=`, `<>`, `>`, `>=`, `<`, `<=`, `is null`, `is not null` |
| Text | `=`, `contains`, `does not contain`, `is null`, `is not null` |
| Date | `between` (`RightStartDate` and `RightEndDate`) |

A filter cannot use a select-column `DisplayName`. `BookQty <> CustodianQty` compares the two source columns.

### `ColumnSchema`

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | Column name |
| `data_type` | `string` | e.g. `varchar`, `int`, `decimal`, `datetime` |
| `is_nullable` | `boolean` | |
| `is_primary_key` | `boolean` | |
| `max_length` | `integer \| null` | |
| `precision` | `integer \| null` | |
| `scale` | `integer \| null` | |
| `default_value` | `any` | |

### `Row`

Object map of column name → value. Primary key columns identify the row for GET/PUT/PATCH/DELETE.

```json
{
  "Id": 12,
  "Symbol": "AAPL",
  "Price": 192.5,
  "AsOf": "2026-07-10T00:00:00Z"
}
```

### `ExportJob`

| Field | Type | Description |
| --- | --- | --- |
| `export_id` | `string` | Opaque ID |
| `status` | `string` | `pending`, `running`, `ready`, `failed` |
| `format` | `string` | `csv` or `json` |
| `download_url` | `string \| null` | Presigned URL when `ready` |
| `error` | `string \| null` | Failure message |
| `created_at` | `string` | ISO 8601 |
| `completed_at` | `string \| null` | ISO 8601 |

### `POST /warehouses/{warehouseId}/views`

Create a view from a [`ViewDefinition`](#viewdefinition). Same object the warehouse **Views** tab saves.

| | |
| --- | --- |
| **Status** | Planned |
| **Scopes** | `warehouses:write` |

The caller also needs **Database Views** access on the warehouse. Tables and columns in the definition must be visible through screen access.

#### Request body

[`ViewDefinition`](#viewdefinition). `Schema`, `Name`, `Table`, and `SelectColumns` are required.

#### Response `201 Created`

The saved definition, same shape as [`GET .../views/{viewName}`](#get-warehouseswarehouseidviewsviewname).

#### Errors

| HTTP | `code` | When |
| --- | --- | --- |
| `409` | `conflict` | `Schema` + `Name` already exists. `message` is the server text |
| `400` | `validation_error` | Missing required field, or the server rejected the definition. `message` is the server text, for example `Table is required.` |
| `502` | `upstream_error` | The save timed out |

```json
{
  "error": {
    "code": "validation_error",
    "message": "Table is required.",
    "details": {}
  }
}
```

#### Position breaks

Book versus custodian quantities. Inner join on as-of date, account, and security. `Diff` is book quantity minus custodian quantity. The where keeps rows where book quantity is not custodian quantity.

Load [`book_positions.csv`](/examples/book_positions.csv) and [`custodian_positions.csv`](/examples/custodian_positions.csv) first. Three rows remain: ACC1/MSFT −5, ACC2/AAPL +5, ACC3/AMZN −5.

<Tabs items={['JavaScript', 'Python']}>
  <Tabs.Tab>

```js
const body = {
  Schema: "ref",
  Name: "position_breaks",
  Description: "Book vs custodian quantity breaks",
  Table: "ref.book_positions",
  JoinCriteria: [
    {
      Table1: "ref.book_positions",
      Table2: "ref.custodian_positions",
      JoinType: "INNER",
      Children: [
        {
          Type: "condition",
          Source1: { Column: "ref.book_positions.AsOfDate" },
          Operator: "=",
          Source2: { Column: "ref.custodian_positions.AsOfDate" },
          CastToDate: true,
        },
        {
          Type: "condition",
          LeadingLogicalOperator: "AND",
          Source1: { Column: "ref.book_positions.Account" },
          Operator: "=",
          Source2: { Column: "ref.custodian_positions.Account" },
        },
        {
          Type: "condition",
          LeadingLogicalOperator: "AND",
          Source1: { Column: "ref.book_positions.Security" },
          Operator: "=",
          Source2: { Column: "ref.custodian_positions.Security" },
        },
      ],
    },
  ],
  GroupByColumns: [],
  SelectColumns: [
    {
      Type: "Reference",
      DisplayName: "Account",
      Source: { Table: "ref.book_positions", ColumnConfig: { ColumnName: "Account" } },
    },
    {
      Type: "Reference",
      DisplayName: "Security",
      Source: { Table: "ref.book_positions", ColumnConfig: { ColumnName: "Security" } },
    },
    {
      Type: "Reference",
      DisplayName: "BookQty",
      Source: { Table: "ref.book_positions", ColumnConfig: { ColumnName: "BookQty" } },
    },
    {
      Type: "Reference",
      DisplayName: "CustodianQty",
      Source: { Table: "ref.custodian_positions", ColumnConfig: { ColumnName: "CustodianQty" } },
    },
    {
      Type: "Calculated",
      DisplayName: "Diff",
      Calculation: JSON.stringify({
        Type: "group",
        Children: [
          { Type: "value", Value: { Column: "ref.book_positions.BookQty" } },
          {
            Type: "value",
            LeadingOperator: "-",
            Value: { Column: "ref.custodian_positions.CustodianQty" },
          },
        ],
      }),
    },
  ],
  Where: {
    Type: "group",
    Children: [
      {
        Type: "condition",
        LeftValue: { Column: "ref.book_positions.BookQty" },
        Operator: "<>",
        RightValue: { Column: "ref.custodian_positions.CustodianQty" },
      },
    ],
  },
};

const response = await fetch(
  "https://portal.cosethub.com/api/v1/warehouses/7/views",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.ACCESS_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(body),
  },
);

const data = await response.json();
```

### `PUT /warehouses/{warehouseId}/views/{viewName}`

Replace a view definition. Send the full [`ViewDefinition`](#viewdefinition). An omitted `Description` or `Table` is cleared. Roles, owners, and tags are kept.

| | |
| --- | --- |
| **Status** | Planned |
| **Scopes** | `warehouses:write` |

#### Path parameters

| Name | Type | Description |
| --- | --- | --- |
| `warehouseId` | `integer` | Warehouse ID |
| `viewName` | `string` | Schema-qualified name. Must match `Schema` and `Name` in the body |

#### Request body

Same as create.
