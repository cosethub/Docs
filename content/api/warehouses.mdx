# Warehouses

Read and write warehouse metadata, schemas, rows, exports, and view definitions.

> **Base:** `/api/v1`  
> **Auth:** `Authorization: Bearer {token}`  
> **Scopes:** `warehouses:read` / `warehouses:write`

Today, many warehouse operations go through ProcessServer websockets. Public REST wraps those ops under `/warehouses/*`.

## Shared types

### `WarehouseSummary`

| Field | Type | Description |
| --- | --- | --- |
| `id` | `integer` | Warehouse ID |
| `name` | `string` | Display name |
| `description` | `string \| null` | Optional description |
| `is_enabled` | `boolean` | Available for use |
| `created_at` | `string` | ISO 8601 |
| `updated_at` | `string \| null` | ISO 8601 |

### `TableSummary`

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | Schema-qualified or warehouse table name |
| `display_name` | `string \| null` | UI label |
| `row_count` | `integer \| null` | Approximate count when known |
| `has_screen_access` | `boolean` | Caller can see this table |

### `ViewSummary`

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | View name |
| `schema` | `string \| null` | Schema |
| `description` | `string \| null` | |

### `ViewDefinition`

The warehouse **Views** tab saves this object. `POST` and `PUT` take it as the body. `GET` returns it.

| Field | Type | Description |
| --- | --- | --- |
| `schema` | `string` | Letters, numbers, and underscores. Max 20. Often `ref` |
| `name` | `string` | Letters, numbers, and underscores. Must start with a letter or underscore. Max 50 |
| `description` | `string \| null` | |
| `base_table` | `string` | Primary table or view |
| `row_mode` | `string` | `all_rows` or `aggregate` |
| `joins` | `ViewJoin[]` | Optional related tables. Use `[]` when there is no join |
| `group_by` | `ViewGroupColumn[]` | Required when `row_mode` is `aggregate` |
| `columns` | `ViewColumn[]` | At least one. Array order is output order |
| `where` | `ViewConditionGroup \| null` | Optional row filter |

`schema` and `name` on a `PUT` must match the path.

### `ViewJoin`

| Field | Type | Description |
| --- | --- | --- |
| `join_type` | `string` | `inner`, `left`, `right`, `full` |
| `left_table` | `string` | Base table, or a table introduced by an earlier join |
| `right_table` | `string` | Table or view being brought in |
| `on` | `ViewConditionGroup` | At least one match condition |

### `ViewGroupColumn`

| Field | Type | Description |
| --- | --- | --- |
| `table` | `string` | Source table |
| `column` | `string` | Category column |

### `ViewColumn`

| Field | Type | Description |
| --- | --- | --- |
| `type` | `string` | `reference`, `calculated`, `conditional`, `sum`, `count`, `avg`, `min`, `max` |
| `display_name` | `string` | Unique in the view. Same character rules as `name` |
| `table` | `string` | `reference` only. Source table |
| `column` | `string` | `reference` only. Source column |
| `expression` | `ViewExpression` | `calculated` only |
| `when` | `object[]` | `conditional` only. Each item is `{ "condition": ViewConditionGroup, "then": ViewValue }` |
| `default` | `ViewValue \| null` | `conditional` only. Used when no `when` matches |
| `distinct` | `boolean` | `sum`, `count`, and `avg` only. Default `false`. Not valid with `COUNT(*)` |
| `inner` | `ViewAggregateInner` | `sum`, `count`, `avg`, `min`, `max` only |

Aggregate column types require `row_mode` `aggregate`. `sum`, `avg`, `min`, and `max` require an inner column, calculated expression, or conditional. `count` with `"inner": { "type": "star" }` is `COUNT(*)`.

### `ViewAggregateInner`

| Field | Type | Description |
| --- | --- | --- |
| `type` | `string` | `column`, `calculated`, `conditional`, or `star` |
| `table` | `string` | `column` only |
| `column` | `string` | `column` only |
| `expression` | `ViewExpression` | `calculated` only |
| `when` | `object[]` | `conditional` only. Same When / Then shape as a conditional column |
| `default` | `ViewValue \| null` | `conditional` only |

`star` is valid only as the inner of `count`.

### `ViewExpression`

A calculated value. Either a column or literal, or an operator node. Nest operator nodes for order of operations: `(Quantity * Price) - Cost` is a `-` node whose `left` is a `*` node.

| Field | Type | Description |
| --- | --- | --- |
| `kind` | `string` | `column` or `literal` on a leaf |
| `table` | `string` | `kind: column`. Source table |
| `column` | `string` | `kind: column`. Source column. Not a select-column display name |
| `value_type` | `string` | `kind: literal`. `number`, `text`, `date`, or `boolean` |
| `value` | `any` | `kind: literal` |
| `operator` | `string` | `+`, `-`, `*`, `/`, `^` |
| `left` | `ViewExpression` | Operator node |
| `right` | `ViewExpression` | Operator node |

### `ViewValue`

One side of a condition, or a conditional Then / Default.

| Field | Type | Description |
| --- | --- | --- |
| `kind` | `string` | `column` or `literal` |
| `table` | `string` | `kind: column` |
| `column` | `string` | `kind: column`. Source column, or a select-column display name when the filter is on calculated output |
| `value_type` | `string` | `kind: literal`. `number`, `text`, `date`, or `boolean` |
| `value` | `any` | `kind: literal` |

### `ViewConditionGroup`

| Field | Type | Description |
| --- | --- | --- |
| `op` | `string` | `and` or `or` |
| `items` | `array` | Each item is a `ViewCondition` (`"type": "condition"`) or a nested group (`"type": "group"`) |

The root `where` and a join `on` omit `type`. A group nested inside `items` sets `"type": "group"`.

### `ViewCondition`

| Field | Type | Description |
| --- | --- | --- |
| `type` | `string` | `condition` |
| `left` | `ViewValue` | Usually a column |
| `operator` | `string` | See below |
| `right` | `ViewValue` | Omit for `is null` and `is not null` |
| `start` | `ViewValue` | Date `between` only. Inclusive start |
| `end` | `ViewValue` | Date `between` only. Inclusive end |
| `cast_to_date` | `boolean` | Join match only. Compare the date and ignore time |

| Left side | Operators |
| --- | --- |
| Number, boolean | `=`, `<>`, `>`, `>=`, `<`, `<=`, `is null`, `is not null` |
| Text | `=`, `contains`, `does not contain`, `is null`, `is not null` |
| Date | `between` (`start` and `end`) |

### `ColumnSchema`

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | Column name |
| `data_type` | `string` | e.g. `varchar`, `int`, `decimal`, `datetime` |
| `is_nullable` | `boolean` | |
| `is_primary_key` | `boolean` | |
| `max_length` | `integer \| null` | |
| `precision` | `integer \| null` | |
| `scale` | `integer \| null` | |
| `default_value` | `any` | |

### `Row`

Object map of column name → value. Primary key columns identify the row for GET/PUT/PATCH/DELETE.

```json
{
  "Id": 12,
  "Symbol": "AAPL",
  "Price": 192.5,
  "AsOf": "2026-07-10T00:00:00Z"
}
```

### `ExportJob`

| Field | Type | Description |
| --- | --- | --- |
| `export_id` | `string` | Opaque ID |
| `status` | `string` | `pending`, `running`, `ready`, `failed` |
| `format` | `string` | `csv` or `json` |
| `download_url` | `string \| null` | Presigned URL when `ready` |
| `error` | `string \| null` | Failure message |
| `created_at` | `string` | ISO 8601 |
| `completed_at` | `string \| null` | ISO 8601 |

### `POST /warehouses/{warehouseId}/views`

Create a view from a [`ViewDefinition`](#viewdefinition). Same object the warehouse **Views** tab saves.

| | |
| --- | --- |
| **Status** | Planned |
| **Scopes** | `warehouses:write` |

The caller also needs **Database Views** access on the warehouse. Tables and columns in the definition must be visible through screen access.

#### Headers

| Name | Required | Description |
| --- | --- | --- |
| `Idempotency-Key` | No | UUID. A retry with the same key and body returns the original view instead of creating a second one |

#### Request body

[`ViewDefinition`](#viewdefinition).

#### Response `201 Created`

The saved definition, same shape as [`GET .../views/{viewName}`](#get-warehouseswarehouseidviewsviewname).

#### Errors

| HTTP | `code` | When |
| --- | --- | --- |
| `409` | `conflict` | `schema` + `name` already exists in the warehouse |
| `422` | `validation_error` | Unknown table or column, duplicate display name, aggregate column while `row_mode` is `all_rows`, `distinct` on `COUNT(*)`, empty `columns`, illegal name |

```json
{
  "error": {
    "code": "validation_error",
    "message": "View definition is invalid.",
    "details": {
      "fields": [
        { "path": "columns[1].display_name", "message": "Display name Account is already used." }
      ]
    }
  }
}
```

Walkthroughs these examples follow: [Reconciliation](/views/examples/reconciliation), [Group by & aggregates](/views/examples/group-by-aggregates).

#### Position breaks

Book versus custodian quantities. Inner join on as-of date, account, and security. `Diff` is book quantity minus custodian quantity. The where keeps rows where `Diff` is not 0.

Load [`book_positions.csv`](/examples/book_positions.csv) and [`custodian_positions.csv`](/examples/custodian_positions.csv) first. Three rows remain: ACC1/MSFT −5, ACC2/AAPL +5, ACC3/AMZN −5.

<Tabs items={['JavaScript', 'Python']}>
  <Tabs.Tab>

```js
const body = {
  schema: "ref",
  name: "position_breaks",
  description: "Book vs custodian quantity breaks",
  base_table: "book_positions",
  row_mode: "all_rows",
  joins: [
    {
      join_type: "inner",
      left_table: "book_positions",
      right_table: "custodian_positions",
      on: {
        op: "and",
        items: [
          {
            type: "condition",
            left: { kind: "column", table: "book_positions", column: "AsOfDate" },
            operator: "=",
            right: { kind: "column", table: "custodian_positions", column: "AsOfDate" },
            cast_to_date: true,
          },
          {
            type: "condition",
            left: { kind: "column", table: "book_positions", column: "Account" },
            operator: "=",
            right: { kind: "column", table: "custodian_positions", column: "Account" },
          },
          {
            type: "condition",
            left: { kind: "column", table: "book_positions", column: "Security" },
            operator: "=",
            right: { kind: "column", table: "custodian_positions", column: "Security" },
          },
        ],
      },
    },
  ],
  columns: [
    { type: "reference", display_name: "Account", table: "book_positions", column: "Account" },
    { type: "reference", display_name: "Security", table: "book_positions", column: "Security" },
    { type: "reference", display_name: "BookQty", table: "book_positions", column: "BookQty" },
    { type: "reference", display_name: "CustodianQty", table: "custodian_positions", column: "CustodianQty" },
    {
      type: "calculated",
      display_name: "Diff",
      expression: {
        operator: "-",
        left: { kind: "column", table: "book_positions", column: "BookQty" },
        right: { kind: "column", table: "custodian_positions", column: "CustodianQty" },
      },
    },
  ],
  where: {
    op: "and",
    items: [
      {
        type: "condition",
        left: { kind: "column", column: "Diff" },
        operator: "<>",
        right: { kind: "literal", value_type: "number", value: 0 },
      },
    ],
  },
};

const response = await fetch(
  "https://portal.cosethub.com/api/v1/warehouses/7/views",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.ACCESS_TOKEN}`,
      "Content-Type": "application/json",
      "Idempotency-Key": "3f1c2a90-7b14-4e2a-9c55-1a0e6d8b4f21",
    },
    body: JSON.stringify(body),
  },
);

const data = await response.json();
```

#### Market value by fund

Load [`positions_by_fund.csv`](/examples/positions_by_fund.csv) first.

```js
  name: "mv_by_fund",
```
