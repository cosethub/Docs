# Warehouses

Read and write warehouse metadata, schemas, rows, and exports.

> **Base:** `/api/v1`  
> **Auth:** `Authorization: Bearer {token}`  
> **Scopes:** `warehouses:read` / `warehouses:write`

Today, many warehouse operations go through ProcessServer websockets. Public REST wraps those ops under `/warehouses/*`.

---

### `GET /warehouses/{warehouseId}/tables/{tableName}/rows`

Query table rows with filter, sort, and pagination.

| | |
| --- | --- |
| **Status** | **New** (today: websocket entity read) |
| **Scopes** | `warehouses:read` |

#### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `filter` | `string` | — | Expression or structured filter (see below) |
| `sort` | `string` | — | `Column:asc` or `Column:desc`; comma-separated |
| `page` | `integer` | `1` | Page number |
| `page_size` | `integer` | `50` | Max `500` |
| `columns` | `string` | — | Comma-separated column subset |

#### Filter examples

Simple:

```
?filter=Symbol:eq:AAPL
?filter=Price:gte:100
```

Combined (AND):

```
?filter=Symbol:eq:AAPL,AsOf:gte:2026-01-01
```

#### Response `200 OK`

```json
{
  "rows": [
    { "Id": 12, "Symbol": "AAPL", "Price": 192.5, "AsOf": "2026-07-10T00:00:00Z" }
  ],
  "pagination": {
    "page": 1,
    "page_size": 50,
    "total_count": 1,
    "has_more": false
  }
}
```

```bash
curl -sS -G \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  --data-urlencode "filter=Symbol:eq:AAPL" \
  --data-urlencode "sort=AsOf:desc" \
  --data-urlencode "page=1" \
  --data-urlencode "page_size=50" \
  "https://{tenant}.ryanplatform.com/api/v1/warehouses/7/tables/dbo.Positions/rows"
```

### `POST /warehouses/{warehouseId}/query`

Structured or ad-hoc query. May return rows inline or an async job id for large results.

| | |
| --- | --- |
| **Status** | **New** (defer for ad-hoc SQL) |
| **Scopes** | `warehouses:read` |

#### Request body

```json
{
  "mode": "structured",
  "table": "dbo.Positions",
  "columns": ["Id", "Symbol", "Price"],
  "filter": { "Symbol": { "eq": "AAPL" } },
  "sort": [{ "column": "AsOf", "direction": "desc" }],
  "limit": 1000,
  "async": false
}
```

| Field | Type | Description |
| --- | --- | --- |
| `mode` | `string` | `structured` (v1). `sql` deferred |
| `table` / `view` | `string` | Target |
| `columns` | `string[]` | Projection |
| `filter` | `object` | Structured filters |
| `sort` | `object[]` | Sort specs |
| `limit` | `integer` | Max rows for sync |
| `async` | `boolean` | If true, returns export-style job |

#### Response `200 OK` (sync)

```json
{
  "rows": [ … ],
  "truncated": false
}
```

#### Response `202 Accepted` (async)

```json
{
  "export_id": "exp_9c2…",
  "status": "pending",
  "poll_url": "/api/v1/warehouses/7/exports/exp_9c2…"
}
```

## Write

### `POST /warehouses/{warehouseId}/tables/{tableName}/rows`

Insert a row.

| | |
| --- | --- |
| **Status** | **New** (today: websocket `SaveUpdateEntity`) |
| **Scopes** | `warehouses:write` |

#### Request body

```json
{
  "row": {
    "Symbol": "MSFT",
    "Price": 425.1,
    "AsOf": "2026-07-11T00:00:00Z"
  }
}
```

#### Response `201 Created`

```json
{
  "row": {
    "Id": 13,
    "Symbol": "MSFT",
    "Price": 425.1,
    "AsOf": "2026-07-11T00:00:00Z"
  }
}
```

```bash
curl -sS -X POST \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"row":{"Symbol":"MSFT","Price":425.1,"AsOf":"2026-07-11T00:00:00Z"}}' \
  "https://{tenant}.ryanplatform.com/api/v1/warehouses/7/tables/dbo.Positions/rows"
```

### `POST /warehouses/{warehouseId}/tables/{tableName}/rows/bulk`

Batch insert and/or update.

| | |
| --- | --- |
| **Status** | **New** (today: websocket `SaveUpdateEntities`) |
| **Scopes** | `warehouses:write` |

#### Request body

```json
{
  "mode": "upsert",
  "key_columns": ["Id"],
  "rows": [
    { "Id": 12, "Symbol": "AAPL", "Price": 193.25 },
    { "Symbol": "GOOG", "Price": 178.4, "AsOf": "2026-07-11T00:00:00Z" }
  ]
}
```

| Field | Type | Description |
| --- | --- | --- |
| `mode` | `string` | `insert`, `update`, or `upsert` |
| `key_columns` | `string[]` | Match keys for update/upsert |
| `rows` | `object[]` | Row payloads |

#### Response `200 OK`

```json
{
  "inserted": 1,
  "updated": 1,
  "failed": 0,
  "errors": []
}
```
