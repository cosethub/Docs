# Jobs & workflows — read

Discover job types, inspect definitions, poll runs, list workflows, and load AI workflow builder chats.

> **Base:** `/api/v1`  
> **Auth:** `Authorization: Bearer {token}`  
> See also: [Jobs & workflows — write](./jobs-workflows-write)

---

## Endpoints

| Method | Path | Action |
| --- | --- | --- |
| `GET` | [`/jobs`](#get-jobs) | List job types |
| `GET` | [`/jobs/{jobId}`](#get-jobsjobid) | Definition + schema |
| `GET` | [`/jobs/{jobId}/runs`](#get-jobsjobidruns) | Run history |
| `GET` | [`/job-runs/{runId}`](#get-job-runsrunid) | Run status + outputs |
| `GET` | [`/workflows`](#get-workflows) | List workflows |
| `GET` | [`/workflows/{workflowId}`](#get-workflowsworkflowid) | Workflow detail |
| `GET` | [`/workflows/{workflowId}/jobs/{jobTreeId}/detail`](#get-workflowsworkflowidjobsjobtreeiddetail) | Job tree detail |
| `GET` | [`/ai-workflow/chats`](#get-ai-workflowchats) | List chats |
| `GET` | [`/ai-workflow/chats/{chatId}`](#get-ai-workflowchatschatid) | Chat detail |

## `GET /jobs`

List runnable job types for the organization.

| | |
| --- | --- |
| **Status** | Planned |
| **Legacy** | `GET /api/ai-workflow/jobs` |
| **Scopes** | `jobs:read` |

### Response `200 OK`

```json
{
  "jobs": [
    {
      "name": "ETL Job",
      "description": "Extract, Transform, and Load data between systems.",
      "job_type": "ETLJob"
    },
    {
      "name": "Group",
      "description": "Container node for workflow structure and scheduling.",
      "job_type": "Group"
    }
  ]
}
```

> Legacy root key: `job_list`.

```bash
curl -sS -H "Authorization: Bearer $ACCESS_TOKEN" \
  "https://{tenant}.ryanplatform.com/api/v1/jobs"
```
