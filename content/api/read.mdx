# Jobs & Workflows — Read API

Public read endpoints for discovering runnable jobs, inspecting workflow definitions, polling run status, and loading AI workflow builder chats.

<Callout type="info">
  **Base URL:** {`https://{tenant}.ryanplatform.com/api/v1`}  
  **Auth:** {`Authorization: Bearer {access_token}`} (OAuth2 client credentials)  
  **Content-Type:** `application/json`  
  **Date format:** ISO 8601 UTC (`2026-07-09T18:30:00Z`)
</Callout>

## Shared types

### `JobTypeSummary`

Catalog entry for a job type the organization can run or add to a workflow.

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | Display name |
| `description` | `string` | Human-readable description |
| `job_type` | `string` | Internal type key (e.g. `ETLJob`, `Group` for container/schedule nodes) |

### `JobParameterSchema`

Parameter definition returned with job detail or from the parameters metadata service.

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | Parameter key |
| `type` | `string` | `string`, `integer`, `boolean`, `enumeration`, `foreign_key`, `date`, `json`, … |
| `default_value` | `any` | Default when unset |
| `description` | `string` | Help text |
| `options` | `string[]` | Allowed values for enumerations |
| `foreign_key_options` | `ForeignKeyOption[]` | {`{ id, name }`} pairs for FK parameters |
| `is_required` | `boolean` | Required at run/create time |
| `is_output` | `boolean` | Output parameter (not an input) |

### `WorkflowJobParameter`

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | Parameter key |
| `value` | `any` | Configured value |

### `WorkflowJob`

| Field | Type | Description |
| --- | --- | --- |
| `id` | `integer` | Job tree ID (present when persisted) |
| `job_type` | `string` | Job type key |
| `job_name` | `string` | Display name |
| `job_instance_id` | `string` | Ephemeral ID in AI draft workflows |
| `access_key` | `uuid` | Transient wiring key within a create/edit payload |
| `parent_access_key` | `uuid \| null` | Parent wiring key |
| `job_key` | `string` | Stable encoded DB key (edit path) |
| `parent_job_key` | `string` | Parent stable key (edit path) |
| `fire_on_success` | `string` | `RunOnSuccess`, `RunOnFailure`, or `RunOnSuccessOrFailure` |
| `parameters` | `WorkflowJobParameter[]` | Configured parameters |

### `WorkflowOutputMapping`

| Field | Type | Description |
| --- | --- | --- |
| `id` | `integer` | Binding ID (when persisted) |
| `source_job_id` | `integer` | Source job tree ID |
| `source_job_access_key` | `uuid` | Source wiring key |
| `source_parameter_name` | `string` | Output parameter on source job |
| `target_job_id` | `integer` | Target job tree ID |
| `target_job_access_key` | `uuid` | Target wiring key |
| `target_parameter_name` | `string` | Input parameter on target job |

### `WorkflowSummary`

| Field | Type | Description |
| --- | --- | --- |
| `id` | `integer` | Root workflow (job tree) ID |
| `parent_id` | `integer \| null` | Parent job tree ID |
| `name` | `string` | Workflow name |
| `key` | `string` | Encoded access key for API job runs |
| `job_type_display` | `string` | Root job type display |
| `is_enabled` | `boolean` | Enabled flag |
| `has_schedule` | `boolean` | Has an active schedule |
| `status` | `StatusCode` | Last known run status |
| `status_time` | `string` | ISO 8601 timestamp of status |
| `children` | `WorkflowSummary[]` | Nested jobs in the tree |

### `StatusCode`

| Field | Type | Description |
| --- | --- | --- |
| `id` | `integer` | Status code ID |
| `name` | `string` | e.g. `Completed`, `Running`, `Failed` |

### `JobRunSummary`

| Field | Type | Description |
| --- | --- | --- |
| `run_id` | `string` | Opaque run identifier (poll via {`GET /job-runs/{runId}`}) |
| `job_id` | `integer` | Job tree ID that was run |
| `name` | `string` | Job display name at run time |
| `status` | `string` | `Running`, `Completed`, `Failed`, `Cancelled`, … |
| `start_time` | `string` | ISO 8601 |
| `end_time` | `string \| null` | ISO 8601 when finished |
| `is_manual_run` | `boolean` | Triggered manually vs schedule |

### `JobRunDetail`

Extends `JobRunSummary` with nested execution tree and output references.

| Field | Type | Description |
| --- | --- | --- |
| `exception` | `string \| null` | Error message when failed |
| `has_children` | `boolean` | Workflow contained child job runs |
| `children` | `JobRunDetail[]` | Child run nodes |
| `output_refs` | `OutputRef[]` | Pointers to job output artifacts |

### `OutputRef`

| Field | Type | Description |
| --- | --- | --- |
| `parameter_name` | `string` | Output parameter name |
| `value` | `any` | Inline value or summary |
| `download_url` | `string \| null` | Presigned URL when output is a file |

### `ChatSummary`

| Field | Type | Description |
| --- | --- | --- |
| `chat_id` | `string` | UUID chat identifier |
| `title` | `string` | Derived from first draft job name |
| `message_count` | `integer` | Total messages |
| `last_message` | `string` | Preview of last message |
| `last_message_role` | `string` | `user` or `assistant` |
| `created_at` | `string` | ISO 8601 |
| `updated_at` | `string \| null` | ISO 8601 |

### `ChatMessage`

| Field | Type | Description |
| --- | --- | --- |
| `role` | `string` | `user` or `assistant` |
| `content` | `string` | Message body |
| `timestamp` | `string \| null` | ISO 8601 |

### Error response

All endpoints return a consistent error envelope on `4xx` / `5xx`:

```json
{
  "error": {
    "code": "not_found",
    "message": "Human-readable description",
    "details": {}
  }
}
```

| HTTP | `code` | When |
| --- | --- | --- |
| `400` | `bad_request` | Invalid parameters or body |
| `401` | `unauthorized` | Missing or invalid token |
| `403` | `forbidden` | Token lacks required scope |
| `404` | `not_found` | Resource not in org |
| `500` | `internal_error` | Unexpected server error |

## {`GET /jobs/{jobId}`}

Return a configured job's definition and parameter schema.

**Scopes:** `jobs:read`

### Path parameters

| Name | Type | Description |
| --- | --- | --- |
| `jobId` | `integer` | Job tree ID |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `include_output` | `boolean` | `false` | Include output parameter definitions in `parameter_schema` |

### Response `200 OK`

```json
{
  "id": 1042,
  "parent_id": 1001,
  "name": "Load warehouse table",
  "key": "xAccessKeyEncoded…",
  "parent_key": "parentKeyEncoded…",
  "job_type": "ETLJob",
  "is_enabled": true,
  "allow_concurrent_runs": true,
  "fire_on_success": "RunOnSuccess",
  "bridge_id": 12,
  "bridge_name": "Production Bridge",
  "parameters": [
    { "name": "SourceTable", "value": "raw_orders" },
    { "name": "TargetTable", "value": "orders" }
  ],
  "parameter_schema": [
    {
      "name": "SourceTable",
      "type": "string",
      "default_value": null,
      "description": "Source table name",
      "options": [],
      "foreign_key_options": [],
      "is_required": true,
      "is_output": false
    }
  ]
}
```

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `id` | `integer` | Job tree ID |
| `parent_id` | `integer \| null` | Parent in workflow tree |
| `name` | `string` | Job name |
| `key` | `string` | API access key for {`POST /jobs/{jobId}/run`} |
| `parent_key` | `string` | Parent job key |
| `job_type` | `string` | Job type key |
| `is_enabled` | `boolean` | |
| `allow_concurrent_runs` | `boolean` | |
| `fire_on_success` | `string \| null` | Run condition vs parent |
| `bridge_id` | `integer \| null` | Execution bridge |
| `bridge_name` | `string \| null` | |
| `parameters` | `WorkflowJobParameter[]` | Current configured values |
| `parameter_schema` | `JobParameterSchema[]` | Type metadata for inputs/outputs |

## {`GET /jobs/{jobId}/runs`}

**Scopes:** `jobs:read`

### Path parameters

| Name | Type | Description |
| --- | --- | --- |
| `jobId` | `integer` | Job tree ID |

### Query parameters

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `page` | `integer` | `1` | Page number (1-based) |
| `page_size` | `integer` | `25` | Page size (max `100`) |
| `status` | `string` | — | Filter: `running`, `completed`, `failed`, `cancelled` |
| `since` | `string` | — | ISO 8601; only runs started after this time |

### Response `200 OK`

```json
{
  "runs": [

      "name": "Load warehouse table",
      "status": "Completed",

    }
  ],
  "pagination": {
    "page": 1,
    "page_size": 25,
    "total_count": 142,
    "has_more": true
  }
}
```

## {`GET /workflows/{workflowId}`}

Return the full workflow definition: jobs, parameters, and output mappings.

**Scopes:** `workflows:read`

### Path parameters

| Name | Type | Description |
| --- | --- | --- |
| `workflowId` | `integer` | Root workflow (job tree) ID |

### Response `200 OK`

Same shape as the workflow create/edit payload:

```json
{
  "jobs_with_parameters": [
    {
      "id": 1001,
      "job_type": "Group",
      "job_name": "Nightly ETL",
      "access_key": "00000000-0000-0000-0000-0000000003e9",
      "parent_access_key": null,
      "job_key": "encodedRootKey…",
      "parent_job_key": null,
      "fire_on_success": null,
      "parameters": [
        { "name": "RecurrencePeriod", "value": "Daily" },
        { "name": "StartDate", "value": "2026-01-01T09:00:00" }
      ]
    },
    {
      "id": 1042,
      "job_type": "ETLJob",
      "job_name": "Load warehouse table",
      "access_key": "00000000-0000-0000-0000-000000000412",
      "parent_access_key": "00000000-0000-0000-0000-0000000003e9",
      "job_key": "encodedChildKey…",
      "parent_job_key": "encodedRootKey…",
      "fire_on_success": "RunOnSuccess",
      "parameters": [
        { "name": "SourceTable", "value": "raw_orders" }
      ]
    }
  ],
  "output_mappings": [
    {
      "id": 7,
      "source_job_id": 1042,
      "source_job_access_key": "00000000-0000-0000-0000-000000000412",
      "source_parameter_name": "RowCount",
      "target_job_id": 1043,
      "target_job_access_key": "00000000-0000-0000-0000-000000000413",
      "target_parameter_name": "ExpectedRows"
    }
  ]
}
```

### Notes

- Jobs are returned in execution order (breadth-first from root).
- Schedule parameters on the root `Group` job are flattened into `parameters` (e.g. `RecurrencePeriod`, `StartDate`).
- `access_key` values are deterministic per job ID within a response; they wire parent/child relationships in create/edit payloads.

## {`GET /workflows/{workflowId}/jobs/{jobTreeId}/detail`}

Return detail for a single job node inside a workflow tree.

**Scopes:** `workflows:read`

### Path parameters

| Name | Type | Description |
| --- | --- | --- |
| `workflowId` | `integer` | Root workflow ID (authorization scope) |
| `jobTreeId` | `integer` | Job tree node ID |

<Callout type="info">
  The `workflowId` path segment scopes authorization to the root workflow. Callers must ensure the job belongs to the given workflow.
</Callout>

### Response `200 OK`

```json
{
  "id": 1042,
  "parent_id": 1001,
  "organization_id": 55,
  "name": "Load warehouse table",
  "key": "encodedKey…",
  "parent_key": "encodedParentKey…",
  "job_type_display": "ETLJob",
  "is_enabled": true,
  "allow_concurrent_runs": true,
  "is_folder": false,
  "bridge_id": 12,
  "bridge_name": "Production Bridge",
  "fire_on_success": "RunOnSuccess",
  "can_schedule": false,
  "job_data_info": [
    { "data_key": "SourceTable", "data_value": "raw_orders" },
    { "data_key": "TargetTable", "data_value": "orders" }
  ],
  "job_schedules": [],
  "tags": ["etl", "nightly"]
}
```

### Response fields (selected)

| Field | Type | Description |
| --- | --- | --- |
| `job_data_info` | {`{ data_key, data_value }[]`} | Configured parameter values |
| `job_schedules` | `JobSchedule[]` | Active schedules on this node |
| `tags` | `string[]` | User-applied tags |
