# Webhooks & events

Subscribe to outbound events and poll an event stream.

> **Base:** `/api/v1`  
> **Auth:** `Authorization: Bearer {token}`  
> **Scopes:** `webhooks:read` / `webhooks:write`  
> **Status:** Planned (coming soon)

---

## Endpoints

| Method | Path | Action |
| --- | --- | --- |
| `GET` | [`/webhooks`](#get-webhooks) | List subscriptions |
| `POST` | [`/webhooks`](#post-webhooks) | Register webhook |
| `PATCH` | [`/webhooks/{webhookId}`](#patch-webhookswebhookid) | Update subscription |
| `DELETE` | [`/webhooks/{webhookId}`](#delete-webhookswebhookid) | Remove subscription |
| `GET` | [`/events`](#get-events) | Poll events |

## Shared types

### `WebhookSubscription`

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Webhook ID |
| `url` | `string` | HTTPS delivery URL |
| `events` | `string[]` | Subscribed event types |
| `secret` | `string` | Signing secret (returned once on create; masked later) |
| `is_enabled` | `boolean` | |
| `created_at` | `string` | ISO 8601 |
| `updated_at` | `string \| null` | ISO 8601 |

### `Event`

| Field | Type | Description |
| --- | --- | --- |
| `id` | `string` | Event ID |
| `type` | `string` | Event type |
| `occurred_at` | `string` | ISO 8601 |
| `organization_id` | `integer` | |
| `data` | `object` | Type-specific payload |

### Event types

| Type | Description |
| --- | --- |
| `job.run.completed` | Job/workflow run finished successfully |
| `job.run.failed` | Job/workflow run failed |
| `warehouse.export.ready` | Async export ready for download |
| `file.upload.completed` | File landed in a file store |
| `table.rows.updated` | Rows inserted/updated/deleted |
| `data_monitor.alert.created` | Table/view data monitor condition matched — new alert |
| `data_monitor.alert.updated` | Data monitor alert acknowledged or closed |

## `POST /webhooks`

Register a webhook.

| | |
| --- | --- |
| **Status** | Planned |
| **Scopes** | `webhooks:write` |

### Request body

```json
{
  "url": "https://hooks.acme.com/ryan",
  "events": [
    "job.run.completed",
    "job.run.failed",
    "warehouse.export.ready",
    "data_monitor.alert.created"
  ],
  "secret": "whsec_optional_custom_secret"
}
```

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `url` | `string` | Yes | HTTPS endpoint |
| `events` | `string[]` | Yes | At least one event type |
| `secret` | `string` | No | If omitted, server generates one |

### Response `201 Created`

```json
{
  "id": "wh_01H…",
  "url": "https://hooks.acme.com/ryan",
  "events": ["job.run.completed", "job.run.failed", "warehouse.export.ready"],
  "secret": "whsec_live_…",
  "is_enabled": true,
  "created_at": "2026-07-11T16:30:00Z",
  "updated_at": null
}
```

Store `secret` immediately — subsequent GETs return a masked value.

```bash
curl -sS -X POST \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://hooks.acme.com/ryan","events":["job.run.completed","job.run.failed"]}' \
  "https://{tenant}.cosethub.com/api/v1/webhooks"
```

## Outbound delivery

When a subscribed event occurs, the platform POSTs to your `url`:

### Headers

| Header | Description |
| --- | --- |
| `Content-Type` | `application/json` |
| `X-Ryan-Event-Id` | Event ID |
| `X-Ryan-Event-Type` | Event type |
| `X-Ryan-Signature` | `sha256=` HMAC of raw body using webhook secret |
| `User-Agent` | `Ryan-Webhooks/1.0` |

### Body

Same shape as a single `Event` object.

### Example payloads

#### `job.run.completed` / `job.run.failed`

```json
{
  "id": "evt_01H…",
  "type": "job.run.completed",
  "occurred_at": "2026-07-11T14:23:04Z",
  "organization_id": 55,
  "data": {
    "job_id": 1042,
    "run_id": "rjh_8f3a…",
    "name": "Load warehouse table",
    "status": "Completed",
    "exception": null
  }
}
```

#### `warehouse.export.ready`

  "type": "data_monitor.alert.created",
  "occurred_at": "2026-08-06T15:02:11Z",
  "organization_id": 55,
  "data": {
    "alert_id": 9001,
    "data_monitor_id": 88,
    "data_monitor_name": "BBG price repair — marl zero",
    "condition_id": 201,
    "status_code_id": 25,
    "status_code_name": "Data Monitor Alert",
    "warehouse_id": 7,
    "entity_name": "ref.v_bbg_price_repair",
    "entity_kind": "view",
    "message": "marl = 0",
    "monitored_at": "2026-08-06T15:02:11Z",
    "trigger_job_id": 1042,
    "source_row": {

### Delivery retries

| Attempt | Delay |
| --- | --- |
| 1 | Immediate |
| 2 | ~1 minute |
| 3 | ~5 minutes |
| 4 | ~30 minutes |
| 5 | ~2 hours |

Expect `2xx` within a short timeout. Non-2xx responses are retried. After exhausting retries, delivery is marked failed (visible in future webhook delivery logs).

### Verifying signatures

```text
signed_payload = raw_request_body
expected = "sha256=" + hex(HMAC_SHA256(secret, signed_payload))
```

Compare `expected` to `X-Ryan-Signature` using a constant-time compare.
