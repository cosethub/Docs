# Checklists

Period-close boards: list checklists, items, runs, periods, and history. Same model as the [Checklists](/checklists) UI.

> **Base:** `/api/v1`  
> **Auth:** `Authorization: Bearer {token}`  
> **Scopes:** `checklists:read` / `checklists:write`

Today these operations run through ProcessServer. Public REST wraps them under `/checklists`.

## Shared types

### `ChecklistSummary`

| Field | Type | Description |
| --- | --- | --- |
| `id` | `integer` | |
| `name` | `string` | |
| `description` | `string \| null` | |
| `period_calendar_id` | `integer` | Cadence source |
| `is_default` | `boolean` | Owner default |
| `owner_user_id` | `integer` | Set to creator on create |
| `updated_at` | `string \| null` | ISO 8601 |

### `ChecklistItem`

| Field | Type | Description |
| --- | --- | --- |
| `id` | `integer` | Master item ID |
| `name` | `string` | |
| `item_type` | `string` | `job_workflow`, `data_monitor`, `web_watcher`, `parameter_value_list` |
| `status` | `string` | Display status for the selected period |
| `milestone_job_id` | `integer \| null` | Watched job |
| `running_job_id` | `integer \| null` | Multi monitoring |
| `data_monitor_id` | `integer \| null` | |
| `escalation_path_id` | `integer \| null` | Who to notify |
| `is_paused` | `boolean` | Suspended |
| `monitoring_type` | `string \| null` | `single` / `multi` |
| `expected_duration_minutes` | `integer \| null` | Late (orange) |
| `tolerance_minutes` | `integer \| null` | Overdue (red) |

### `item_type` mapping

| `item_type` | Product |
| --- | --- |
| `job_workflow` | Job, quick job, or task |
| `data_monitor` | [Data monitor](/warehouses/data-monitors) |
| `web_watcher` | Web watcher (`DataMonitorBuilder` / WebWatcher in product) |
| `parameter_value_list` | Iterator |

## `PATCH /checklists/{checklistId}/detail-items/{detailItemId}`

Update a **task** status/notes/progress or a **data-monitor alert** response.

| | |
| --- | --- |
| **Status** | Planned (today: `UpdateChecklistDetailItems`) |
| **Scopes** | `checklists:write` |

```json
{
  "status": "completed",
  "progress": 100,
  "notes": "FA file signed off",
  "response_status": null
}
```

For an alert, set `response_status` to `acknowledged` or `closed`. Closed alerts cannot be reopened.
