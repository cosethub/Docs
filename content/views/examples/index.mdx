## Walkthroughs

| Example | What you practice |
| --- | --- |
| [Reconciliation](./reconciliation) | Join book vs custodian, compare quantities |
| [Bloomberg price backfill](./bloomberg-price-backfill) | Left join prices by security + date |
| [Conditional columns](./conditional-columns) | CASE-style When / Then (long-short + asset class) |
| [Group by & aggregates](./group-by-aggregates) | SUM / COUNT rolled up by Fund (and Strategy) |
| [Calculated columns](./calculated-columns) | MarketValue and PnL from Quantity × Price − Cost |
| [Where filters](./where-filters) | Active-only rows for a single as-of date |

## How to use them

1. Load the CSVs into tables in a test warehouse (any names you like — the docs use simple names).
2. Build the view as described on each page.
3. Compare your result to the expected output table on that page.

These are teaching toys, not production schemas.
