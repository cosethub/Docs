# Group by & aggregates

**Goal:** Roll positions up by fund (and optionally strategy), then measure with **SUM** and **COUNT**.

This uses **aggregates / roll-up** mode — one output row per group, not one row per position.

## Build the view — MV by fund

1. **Create View**
2. **Table** = `positions_by_fund`
3. **I want to** = aggregates / rolls up groups of rows
4. **Group by** → add **Fund**
5. **Select columns**
   - Reference: Fund
   - **SUM** MarketValue → display name `TotalMV`
   - **COUNT** (leave column empty for `COUNT(*)`) → display name `PositionCount`
6. **Save**

### Expected result

| Fund | TotalMV | PositionCount |
| --- | --- | --- |
| Alpha | 136500 | 3 |
| Beta | 90750 | 3 |
| Gamma | 567500 | 2 |

## Optional: finer grain — Fund + Strategy

1. Keep aggregate mode.
2. **Group by** Fund **and** Strategy.
3. Select Fund, Strategy, SUM(MarketValue), COUNT(*).

### Expected result (Fund + Strategy)

| Fund | Strategy | TotalMV | PositionCount |
| --- | --- | --- | --- |
| Alpha | LongEquity | 38000 | 2 |
| Alpha | Macro | 98500 | 1 |
| Beta | LongEquity | 40750 | 2 |
| Beta | Credit | 50000 | 1 |
| Gamma | Macro | 542500 | 1 |
| Gamma | Credit | 25000 | 1 |

## Optional: distinct count

To count unique securities per fund:

- **COUNT** Security with **Distinct** checked → e.g. Alpha has 3 distinct securities
