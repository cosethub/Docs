# Getting Started

## Project structure

```
content/          MDX documentation pages
app/              Next.js app router + Nextra layout
mdx-components.js Theme component overrides
next.config.mjs   Next.js + Nextra configuration
```

## Writing pages

Create `.mdx` files in `content/`. Use `_meta.js` files to control sidebar order and labels.

## Deploying to GitHub Pages

Push this repo to GitHub, enable **GitHub Pages** with source set to **GitHub Actions**, and the included workflow will build and deploy on every push to `main`.
