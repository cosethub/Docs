# IMAP for Email Check

**Goal:** Store mailbox login once, then watch that inbox with Email Check.

## 1. Create the credential

1. **Credential Hub** → **Create Credential**
2. **Credential Name:** `Ops Inbox IMAP`
3. **Credential Type:** **Email - IMAP**
4. Share with the organization if needed
5. Under **IMAP Server Settings**:

| Field | Example |
| --- | --- |
| **Mail Server: Host** | `outlook.office365.com` |
| **Remote Server: Port** | `993` |
| **Mail Server: Is SSL Enabled?** | On |
| **Mail Server: UserName** | `ops@yourfirm.com` |
| **Mail Server: Password** | (secret) |
| **Sender Address** | Often the same mailbox address |
| **Timeout (in seconds)** | As needed |

6. **Create & Validate**

## Microsoft or Google mail?

If the mailbox uses OAuth instead of a password, create **Microsoft OAuth** or **Google OAuth**, complete **Login**, then select that credential on Email Check (same **Credential** field).

## 2. Use it on Email Check

1. Open an **Email Check** job.
2. **Credential** → `Ops Inbox IMAP` (or your OAuth credential).
3. Set search rules and **Save attachments** as needed.
