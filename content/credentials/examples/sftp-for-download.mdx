# SFTP for FTP Download

**Goal:** Store SFTP login once, then pick it on FTP Download (and Monitor / Transmit).

## 1. Create the credential

1. **Credential Hub** → **Create Credential**
2. **Credential Name:** `PB SFTP Prod`
3. **Credential Type:** **FTP/SFTP**
4. Turn on **Share Credential with Organization?** if workflows should reuse it
5. Under **FTP Server Settings**:

| Field | Example |
| --- | --- |
| **FTP Server: Host Name** | `sftp.primebroker.com` |
| **FTP Server: Port** | `22` |
| **FTP Server: UserName** | `ryan_ops` |
| **FTP Server: Password** | (secret) |
| **Secure FTP?** | On (this is SFTP) |
| **SFTP: SSH Host Key** | If your host requires it |
| **SFTP: Private Key** / **Pass Phrase** | If you use key auth instead of (or with) password |

6. **Create & Validate**

{/* SCREENSHOT: FTP/SFTP Connection Settings with Secure FTP on */}

## 2. Use it on a job

On **FTP Download** (or Monitor / Transmit):

- **FTP Server Credentials** → `PB SFTP Prod`

Then set remote source path and local destination as usual.
