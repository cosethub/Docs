# SQL for warehouse / Table to CSV

**Goal:** Create a SQL (or PostgreSQL) credential, attach it to a data warehouse, then export tables/views with Table to CSV.

**Table to CSV** does not pick a SQL credential directly. It picks a **warehouse**. The warehouse already has staging/warehouse SQL accounts.

## 1. Create the SQL credential

1. **Credential Hub** → **Create Credential**
2. **Credential Name:** `Warehouse SQL`
3. **Credential Type:** **SQL Server** (or **Postgre SQL**)
4. Share with the organization
5. Under **SQL Server Settings** / **PostgreSQL Settings**:

Pick **Credential Format**:

- **Connection String** — paste a full connection string, or
- **Server Details** — Server Name, Authentication Type (**SQL Login** / **Windows Authentication**), User Name, Password, Database Name, Timeout

Optional: **Cloud accessible connection** if the cloud app must reach this database without a bridge.

6. **Create & Validate**

## 2. Attach it to the warehouse

In **Data Warehouses** administration for your warehouse, set the staging / warehouse SQL account fields to `Warehouse SQL` (labels like **Select Staging SQL Server Account** / **Select Warehouse SQL Server Account**, or PostgreSQL equivalents).

{/* SCREENSHOT: Warehouse SQL account pickers */}

## 3. Export with Table to CSV

1. Workflow job **Table to CSV** (Export Table Data to CSV).
2. Choose the warehouse database.
3. Pick a **table** or **`View: …`**.
4. Set destination CSV settings.

No separate credential field on the job — the warehouse connection is enough.

## Direct SQL jobs

For **SQL Text/Procedure** or **SQL Bulk Load**, pick the credential on the job itself (**Credentials** / **Database credentials**) — you do not have to go through a warehouse.
