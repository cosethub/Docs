# SMTP for Email

**Goal:** Store SMTP send credentials once, then use them on the Email job (alerts, file delivery).

## 1. Create the credential

1. **Credential Hub** → **Create Credential**
2. **Credential Name:** `Ops SMTP`
3. **Credential Type:** **Email - SMTP**
4. Share with the organization if needed
5. Under **SMTP Server Settings**:

| Field | Example |
| --- | --- |
| **Mail Server: Host** | `smtp.office365.com` |
| **Remote Server: Port** | `587` |
| **Mail Server: Is SSL Enabled?** / **Explicit SSL** | Per your provider |
| **Mail Server: UserName** | `ops@yourfirm.com` |
| **Mail Server: Password** | (secret) |
| **Sender Address** | `ops@yourfirm.com` |
| **Timeout (in seconds)** | As needed |

## OAuth instead?

Email can also use **Microsoft OAuth** or **Google OAuth**. Create that type, complete **Login**, then select it on the Email job.

## 2. Use it on Email

1. Open an **Email** job (for example an **On failure** alert under Email Check or FTP Monitor).
2. **Credential** / SMTP field → `Ops SMTP`.
3. Set recipients, subject, body, and optional attachments.
