# Examples

Short setups for the credentials you will create most often.

| Example | Credential type | Used by |
| --- | --- | --- |
| [SFTP for FTP Download](/credentials/examples/sftp-for-download) | FTP/SFTP | FTP Download / Monitor / Transmit |
| [IMAP for Email Check](/credentials/examples/imap-for-email-check) | Email - IMAP | Email Check |
| [SQL for warehouse / Table to CSV](/credentials/examples/sql-warehouse) | SQL Server or Postgre SQL | Warehouse → Table to CSV |
| [SMTP for Email](/credentials/examples/smtp-for-email) | Email - SMTP | Email job |

Also see [PGP and RSA keys](/credentials/pgp-and-rsa) for decrypt/encrypt file paths.
