# Postgre SQL

PostgreSQL connection for jobs and data warehouses.

> Display name in the hub is Postgre SQL (with a space).

| | |
| --- | --- |
| **Group** | Database |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | SQL jobs and warehouses that use PostgreSQL |

## How it works

1. Same pattern as SQL Server: connection string or server details.
2. Optionally enable Cloud accessible connection.
3. Use wherever PostgreSQL warehouses or jobs are configured.

## Connection Settings fields

- **Credential Format**
- **Cloud accessible connection**
- **Connection String**
- **Server Name**
- **Authentication Type**
- **User Name**
- **Password**
- **Database Name**
- **Timeout (in seconds)**

## In a job

Jobs that need this type show a credential dropdown (for example **FTP Server Credentials** or **Credential**). You can also use **Add New … Credential** from some job forms.
