# Postgre SQL

PostgreSQL connection for jobs and data warehouses.

> Display name in the hub is Postgre SQL (with a space).

| | |
| --- | --- |
| **Group** | Database |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | SQL jobs and warehouses that use PostgreSQL |

## How it works

1. Same pattern as SQL Server: connection string or server details.
2. Optionally enable Cloud accessible connection.
3. Use wherever PostgreSQL warehouses or jobs are configured.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Credential Format** | How you supply connection details: **Connection String** or discrete **Server Details** fields. |
| **Cloud accessible connection** | When on, marks the database as reachable from cloud / off-network Bridges (use only when that path is intended). |
| **Connection String** | Full PostgreSQL connection string when Credential Format is Connection String (host, database, user, and options). |
| **Server Name** | PostgreSQL host name or IP when using Server Details. |
| **Authentication Type** | How the server authenticates the user (for example password / configured server auth mode). |
| **User Name** | Database login role. |
| **Password** | Password for that role. |
| **Database Name** | Target database name. |
| **Timeout (in seconds)** | Connection / command timeout for warehouse and SQL jobs using this credential. |
