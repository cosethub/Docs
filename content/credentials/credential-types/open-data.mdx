# Open Data

App token for open data sources.

| | |
| --- | --- |
| **Group** | Data |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Open Data Job |

## How it works

1. Paste your App Token (obtain from the provider link in the form).
2. Select on Open Data Job.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **App Token** | Provider-issued application token / API key for the open data source. Obtain it from the provider link shown in the form. |

On **Open Data Job**, pick this app token credential. You can also use **Add New … Credential** from some job forms when available.
