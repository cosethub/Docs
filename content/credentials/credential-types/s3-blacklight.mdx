# S3 Partners - Blacklight

Login for S3 Partners Blacklight extracts.

| | |
| --- | --- |
| **Group** | Finance |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | S3 Blacklight to File |

## How it works

1. Enter UserName and Password.
2. Select on S3 Blacklight to File.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **UserName** | S3 Partners Blacklight portal / API username. |
| **Password** | Password for that Blacklight account. |
