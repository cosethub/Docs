# Backstop

Backstop web service login for Backstop to File.

| | |
| --- | --- |
| **Group** | Finance |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Backstop to File |

## How it works

1. Enter Application Server (for example xyz.backstopsolutions.com), User Name, and Password.
2. Select as Backstop Account on Backstop to File.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Application Server** | Backstop site host for your firm (for example `yourfirm.backstopsolutions.com`), without path suffixes. |
| **User Name** | Backstop login used for the web service / report pull. |
| **Password** | Password for that Backstop user. Prefer a dedicated integration account. |

## In a job

On **Backstop to File**, pick this credential as the Backstop account. You can also use **Add New … Credential** from some job forms when available.
