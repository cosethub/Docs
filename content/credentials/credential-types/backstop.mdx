# Backstop

Backstop web service login for Backstop to File.

| | |
| --- | --- |
| **Group** | Finance |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Backstop to File |

## How it works

1. Enter Application Server (for example xyz.backstopsolutions.com), User Name, and Password.
2. Select as Backstop Account on Backstop to File.

## Connection Settings fields

- **Application Server**
- **User Name**
- **Password**
