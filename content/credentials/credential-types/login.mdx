# Login

Generic username/password for web login steps (for example Web Watcher).

| | |
| --- | --- |
| **Group** | Web |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Web Watcher |

## How it works

1. Enter Username and Password.
2. Attach where a simple login credential is required.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Username** | Generic web login username for automation that posts credentials to a form or portal. |
| **Password** | Password for that login. |

## In a job

On **Web Watcher** (and similar), pick this as the login credential. You can also use **Add New … Credential** from some job forms when available.
