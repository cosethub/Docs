# Unix / SSH

SSH access to remote Unix hosts for commands and health checks.

> Job field is often labeled SSH Server Credentials.

| | |
| --- | --- |
| **Group** | Systems |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Unix Command, Unix Health Monitor |

## How it works

1. Enter host, username, password and/or private key file, and port.
2. Select on Unix Command or Unix Health Monitor.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Remote Server: Host Name** | SSH server hostname or IP. |
| **Remote Server: UserName** | SSH login user. |
| **Remote Server: Password** | Password for password-based SSH. Optional if you use a private key only. |
| **Private Key File** | Path on the Bridge to the SSH private key (OpenSSH/PEM) when using key auth. |
| **Remote Server: Port** | SSH port. Default is usually `22`. |

On **Unix Command** / **Unix Health Monitor**, pick this as **SSH Server Credentials**. You can also use **Add New … Credential** from some job forms when available.
