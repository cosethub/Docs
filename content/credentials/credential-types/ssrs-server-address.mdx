# SSRS Server Address

Stores the SSRS server URL used by reporting configuration.

| | |
| --- | --- |
| **Group** | Database |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | SSRS / Reporting configuration |

## How it works

1. Enter SSRS Server URL.
2. Use from Reporting / SSRS setup that needs a server address credential.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **SSRS Server URL** | Base SSRS report server URL used by reporting configuration (web service endpoint). |
