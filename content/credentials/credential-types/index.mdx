# Credential types
Each type stores a different kind of secret or connection. Pick the type when you **Create Credential**.

### Email
| Type | What it is for |
| --- | --- |
| [Email - IMAP](/credentials/credential-types/email-imap) | Mailbox login for watching and reading email (inbound). |
| [Email - SMTP](/credentials/credential-types/email-smtp) | SMTP server login for sending email from workflows. |
| [Google OAuth](/credentials/credential-types/google-oauth) | OAuth login for Google mail accounts used by Email and Email Check. |
| [Microsoft OAuth](/credentials/credential-types/microsoft-oauth) | OAuth login for Microsoft mail accounts used by Email and Email Check. |

### File transfer
| Type | What it is for |
| --- | --- |
| [FTP/SFTP](/credentials/credential-types/ftp-sftp) | Connect to FTP or SFTP servers to download, upload, or watch remote files. |

### Database
| Type | What it is for |
| --- | --- |
| [Postgre SQL](/credentials/credential-types/postgresql) | PostgreSQL connection for jobs and data warehouses. |
| [SQL Server](/credentials/credential-types/sql-server) | SQL Server connection for jobs and data warehouses. |
| [SQL Server - SSRS](/credentials/credential-types/sql-server-ssrs) | Credentials for running SQL Server Reporting Services reports. |
| [SSRS Server Address](/credentials/credential-types/ssrs-server-address) | Stores the SSRS server URL used by reporting configuration. |

### Web
| Type | What it is for |
| --- | --- |
| [HTTP/HTTPs](/credentials/credential-types/http-https) | Username and password for HTTP or HTTPS downloads. |
| [Login](/credentials/credential-types/login) | Generic username/password for web login steps (for example Web Watcher). |

### Systems
| Type | What it is for |
| --- | --- |
| [Microsoft Remote Desktop](/credentials/credential-types/microsoft-rdp) | RDP server login details. |
| [Unix / SSH](/credentials/credential-types/unix-ssh) | SSH access to remote Unix hosts for commands and health checks. |

### Cloud
| Type | What it is for |
| --- | --- |
| [Amazon Identity Access Management](/credentials/credential-types/amazon-iam) | AWS access keys for automation and related cloud tasks. |

### Finance
| Type | What it is for |
| --- | --- |
| [Backstop](/credentials/credential-types/backstop) | Backstop web service login for Backstop to File. |
| [Bloomberg](/credentials/credential-types/bloomberg) | Bloomberg API service host settings for Bloomberg file jobs. |
| [EZE Analytics Interface](/credentials/credential-types/eze-analytics-interface) | Client credentials for the EZE Analytics REST API. |
| [Geneva](/credentials/credential-types/geneva) | Geneva application and related SSH settings for Geneva jobs and warehouse extracts. |
| [MAPS Interface](/credentials/credential-types/maps-interface) | OAuth-style client credentials for the MAPS API. |
| [S3 Partners - Blacklight](/credentials/credential-types/s3-blacklight) | Login for S3 Partners Blacklight extracts. |

### Reporting
| Type | What it is for |
| --- | --- |
| [Microsoft Power BI](/credentials/credential-types/microsoft-power-bi) | Power BI authentication (master user or service principal). |
| [Power BI Server Address](/credentials/credential-types/power-bi-server-address) | Stores the Power BI server URL. |

### Data
| Type | What it is for |
| --- | --- |
| [Open Data](/credentials/credential-types/open-data) | App token for open data sources. |

### Storage
| Type | What it is for |
| --- | --- |
| [Egnyte Cloud Storage Platform](/credentials/credential-types/egnyte) | Egnyte domain and API credentials for cloud file storage. |
