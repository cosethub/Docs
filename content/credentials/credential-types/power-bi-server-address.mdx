# Power BI Server Address

Stores the Power BI server URL.

| | |
| --- | --- |
| **Group** | Reporting |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Power BI reporting |

## How it works

1. Enter Power BI Server URL.
2. Use from Power BI report configuration.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Power BI Server URL** | Base URL of the Power BI Report Server or service endpoint your reports call (as provided by your BI admin). |
