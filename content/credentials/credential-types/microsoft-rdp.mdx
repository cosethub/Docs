# Microsoft Remote Desktop

RDP server login details.

| | |
| --- | --- |
| **Group** | Systems |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | RDP-related validation / access |

## How it works

1. Enter Server Name, User Name, and Password.
2. Use where RDP access is required.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Server Name** | RDP host name or IP of the Windows machine. |
| **User Name** | Windows account for the remote desktop session (DOMAIN\\user or user@domain as required). |
| **Password** | Password for that Windows account. |
