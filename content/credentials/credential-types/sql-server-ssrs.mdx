# SQL Server - SSRS

Credentials for running SQL Server Reporting Services reports.

| | |
| --- | --- |
| **Group** | Database |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | SSRS Report Run |

## How it works

1. Enter report server URL, data source, and SSRS user details.
2. Optionally allow unvalidated SSL or Geneva report options.
3. Select on SSRS Report Run.

## Connection Settings fields

- **Report Server URL**
- **Data Source Name**
- **User Name**
- **Password**
- **SSRS Server Domain**
- **SSRS User Name**
- **SSRS Password**
- **Allow Unvalidated SSL Certificates?**
- **Use for Geneva Reports?**

## In a job

Jobs that need this type show a credential dropdown (for example **FTP Server Credentials** or **Credential**). You can also use **Add New … Credential** from some job forms.
