# Email - SMTP

SMTP server login for sending email from workflows.

> Job field is often labeled SMTP Server Credentials or Credential.

| | |
| --- | --- |
| **Group** | Email |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Email, Global Relay SMTP Archive |

## How it works

1. Enter SMTP host, port, SSL options, username, and password.
2. Set sender address.
3. Select this credential on the Email job (OAuth also supported).

## Connection Settings fields

- **Mail Server: Host**
- **Remote Server: Port**
- **Mail Server: Is SSL Enabled?**
- **Explicit SSL**
- **Mail Server: UserName**
- **Mail Server: Password**
- **Sender Address**
- **Timeout (in seconds)**

## In a job

Jobs that need this type show a credential dropdown (for example **FTP Server Credentials** or **Credential**). You can also use **Add New … Credential** from some job forms.
