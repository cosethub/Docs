# Email - SMTP

SMTP server login for sending email from workflows.

> Job field is often labeled SMTP Server Credentials or Credential.

| | |
| --- | --- |
| **Group** | Email |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Email, Global Relay SMTP Archive |

## How it works

1. Enter SMTP host, port, SSL options, username, and password.
2. Set sender address.
3. Select this credential on the Email job (OAuth also supported).

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Mail Server: Host** | SMTP server hostname (for example `smtp.office365.com` or `smtp.gmail.com`). |
| **Remote Server: Port** | SMTP port. Common values: `587` (STARTTLS), `465` (SMTPS), or `25` (relay). |
| **Mail Server: Is SSL Enabled?** | When on, negotiate a secure SMTP session. |
| **Explicit SSL** | Use explicit SSL/STARTTLS (upgrade after connect) instead of implicit SSL on connect. Match what your mail provider documents. |
| **Mail Server: UserName** | SMTP authentication user — often the full email address. |
| **Mail Server: Password** | SMTP password or app password. |
| **Sender Address** | Default From address used when jobs send mail with this credential. |
| **Timeout (in seconds)** | How long the Bridge waits for the SMTP server before failing. |

## In a job

On **Email** (and related send jobs), pick this as **SMTP Server Credentials** / **Credential**. You can also use **Add New … Credential** from some job forms when available.
