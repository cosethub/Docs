# MAPS Interface

OAuth-style client credentials for the MAPS API.

| | |
| --- | --- |
| **Group** | Finance |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | MAPS API |

## How it works

1. Enter Access Token URL, Client ID, Client Secret, and MAPS API URL.
2. Select on MAPS API jobs.

## Connection Settings fields

- **Access Token URL**
- **Client ID**
- **Client Secret**
- **MAPS API URL**

## In a job

Jobs that need this type show a credential dropdown (for example **FTP Server Credentials** or **Credential**). You can also use **Add New … Credential** from some job forms.

See [Getting started](/credentials/getting-started) and [Examples](/credentials/examples).
