# MAPS Interface

OAuth-style client credentials for the MAPS API.

| | |
| --- | --- |
| **Group** | Finance |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | MAPS API |

## How it works

1. Enter Access Token URL, Client ID, Client Secret, and MAPS API URL.
2. Select on MAPS API jobs.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Access Token URL** | OAuth token endpoint URL used to exchange client credentials for an access token. |
| **Client ID** | MAPS API OAuth client ID. |
| **Client Secret** | MAPS API OAuth client secret. |
| **MAPS API URL** | Base URL of the MAPS API for your environment. |

## In a job

On **MAPS API** jobs, pick this credential for token + API access. You can also use **Add New … Credential** from some job forms when available.

See [Getting started](/credentials/getting-started) and [Examples](/credentials/examples).
