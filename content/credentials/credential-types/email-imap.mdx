# Email - IMAP

Mailbox login for watching and reading email (inbound).

| | |
| --- | --- |
| **Group** | Email |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Email Check |

## How it works

1. Enter mail host, port, SSL, username, and password.
2. Set sender address and timeout if needed.
3. Select this credential on Email Check (OAuth types also work there).

## Connection Settings fields

- **Mail Server: Host**
- **Remote Server: Port**
- **Mail Server: Is SSL Enabled?**
- **Mail Server: UserName**
- **Mail Server: Password**
- **Sender Address**
- **Timeout (in seconds)**

Jobs that need this type show a credential dropdown (for example **FTP Server Credentials** or **Credential**). You can also use **Add New … Credential** from some job forms.
