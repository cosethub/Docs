# Email - IMAP

Mailbox login for watching and reading email (inbound).

| | |
| --- | --- |
| **Group** | Email |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Email Check |

## How it works

1. Enter mail host, port, SSL, username, and password.
2. Set sender address and timeout if needed.
3. Select this credential on Email Check (OAuth types also work there).

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Mail Server: Host** | IMAP server hostname (for example `outlook.office365.com` or `imap.gmail.com`). |
| **Remote Server: Port** | IMAP port. Common values: `993` (IMAPS/SSL) or `143` (STARTTLS/plain depending on config). |
| **Mail Server: Is SSL Enabled?** | When on, use SSL/TLS for the IMAP session (typical for port 993). |
| **Mail Server: UserName** | Mailbox login — often the full email address. |
| **Mail Server: Password** | Mailbox password or app password when the provider requires it. |
| **Sender Address** | Optional From / sender address associated with this mailbox for matching or display. |
| **Timeout (in seconds)** | How long the Bridge waits for the mail server before failing the connection check or job step. |

## In a job

On **Email Check**, pick this credential (or a Google/Microsoft OAuth credential) for the mailbox. You can also use **Add New … Credential** from some job forms when available.

See [Getting started](/credentials/getting-started) and [Examples](/credentials/examples).
