# Egnyte Cloud Storage Platform

Egnyte domain and API credentials for cloud file storage.

| | |
| --- | --- |
| **Group** | Storage |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Egnyte file storage integrations |

## How it works

1. Enter Domain, UserName, Password, Key, and Secret.
2. Use where Egnyte object storage is configured.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Domain** | Egnyte Connect domain name (the `{domain}` in `https://{domain}.egnyte.com`), not a full URL. |
| **UserName** | Egnyte user used for the resource-owner / password OAuth flow. |
| **Password** | Password for that Egnyte user. |
| **Key** | Egnyte API key (`client_id`) from the Egnyte Developer Portal. |
| **Secret** | Egnyte API secret (`client_secret`) issued with the API key. |

Select this credential wherever Egnyte storage is configured for the job. You can also use **Add New … Credential** from some job forms when available.
