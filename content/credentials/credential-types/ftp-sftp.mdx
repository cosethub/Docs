# FTP/SFTP

Connect to FTP or SFTP servers to download, upload, or watch remote files.

> Job field is usually labeled FTP Server Credentials.

| | |
| --- | --- |
| **Group** | File transfer |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | FTP Download, FTP Transmit, FTP Monitor |

## How it works

1. Create an FTP/SFTP credential with host, port, username, and password.
2. Turn on Secure FTP? for SFTP; add SSH host key / private key / passphrase if needed.
3. Pick this credential in FTP Download, FTP Transmit, or FTP Monitor.

## Connection Settings fields

- **FTP Server: Host Name**
- **FTP Server: Port**
- **FTP Server: UserName**
- **FTP Server: Password**
- **Use Passive FTP?**
- **Secure FTP?**
- **SFTP: SSH Host Key**
- **SFTP: Private Key**
- **SFTP: Pass Phrase**

Jobs that need this type show a credential dropdown (for example **FTP Server Credentials** or **Credential**). You can also use **Add New … Credential** from some job forms.
