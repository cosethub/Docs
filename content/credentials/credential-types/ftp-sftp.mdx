# FTP/SFTP

Connect to FTP or SFTP servers to download, upload, or watch remote files.

> Job field is usually labeled FTP Server Credentials.

| | |
| --- | --- |
| **Group** | File transfer |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | FTP Download, FTP Transmit, FTP Monitor |

## How it works

1. Create an FTP/SFTP credential with host, port, username, and password.
2. Turn on Secure FTP? for SFTP; add SSH host key / private key / passphrase if needed.
3. Pick this credential in FTP Download, FTP Transmit, or FTP Monitor.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **FTP Server: Host Name** | Hostname or IP of the FTP/SFTP server (no protocol prefix). |
| **FTP Server: Port** | Server port. Common defaults: `21` (FTP), `22` (SFTP). |
| **FTP Server: UserName** | Login user on the remote server. |
| **FTP Server: Password** | Password for password-based auth. Leave blank if you use key auth only. |
| **Use Passive FTP?** | For classic FTP only: use passive mode (recommended through firewalls/NAT). Ignored for SFTP. |
| **Secure FTP?** | When on, use SFTP (SSH file transfer) instead of plain FTP. |
| **SFTP: SSH Host Key** | Optional known-host / host key fingerprint so the Bridge can verify the SFTP server identity. |
| **SFTP: Private Key** | Optional client private key (PEM/OpenSSH) for key-based SFTP auth. |
| **SFTP: Pass Phrase** | Passphrase for the private key file, if the key is encrypted. |

On FTP jobs, pick this as **FTP Server Credentials**. You can also use **Add New … Credential** from some job forms when available.
