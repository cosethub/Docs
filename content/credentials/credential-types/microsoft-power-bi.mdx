# Microsoft Power BI

Power BI authentication (master user or service principal).

| | |
| --- | --- |
| **Group** | Reporting |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Power BI to File, Power BI reporting |

## How it works

1. Choose Authentication Type: Master User or Service Principal.
2. Fill Client ID and either master user password or tenant + application secret.
3. Use with Power BI to File / reporting.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Authentication Type** | How the Bridge authenticates: **Master User** (licensed user password) or **Service Principal** (app registration). |
| **Client ID [also known as Application ID]** | Microsoft Entra application (client) ID of the app registration. |
| **Master User Name** | Power BI / Entra user UPN when using Master User auth (must be licensed for the APIs you call). |
| **Master User Password** | Password for the master user. Prefer service principal in production. |
| **Tenant ID** | Microsoft Entra directory (tenant) ID. Required for service principal auth. |
| **Application Secret Key** | Client secret value from the app registration (Certificates & secrets). Required for service principal auth. |

## In a job

On **Power BI to File** / reporting jobs, pick this Power BI auth credential. You can also use **Add New … Credential** from some job forms when available.
