# Microsoft OAuth

OAuth login for Microsoft mail accounts used by Email and Email Check.

| | |
| --- | --- |
| **Group** | Email |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Email, Email Check |

## How it works

1. Choose Microsoft OAuth and complete Login to grant access.
2. Tokens (access / refresh) are stored on the credential.
3. Use Refresh credential details when tokens need updating.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Login** | Starts the Microsoft Entra / Microsoft account consent flow for the mailbox. |
| **Token Type** | OAuth token type returned by Microsoft (typically `Bearer`). Usually filled after Login. |
| **Scope** | Granted Microsoft Graph / Outlook scopes. Filled after Login. |
| **Access Token** | Short-lived access token. Populated by Login or **Refresh credential details**. |
| **Refresh Token** | Refresh token used to renew access. Populated by Login. |

## In a job

On **Email** / **Email Check**, pick this OAuth credential instead of IMAP/SMTP password auth. You can also use **Add New … Credential** from some job forms when available.
