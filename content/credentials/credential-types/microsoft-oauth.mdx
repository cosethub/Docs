# Microsoft OAuth

OAuth login for Microsoft mail accounts used by Email and Email Check.

| | |
| --- | --- |
| **Group** | Email |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Email, Email Check |

## How it works

1. Choose Microsoft OAuth and complete Login to grant access.
2. Tokens (access / refresh) are stored on the credential.
3. Use Refresh credential details when tokens need updating.

## Connection Settings fields

- **Login**
- **Token Type**
- **Scope**
- **Access Token**
- **Refresh Token**

## In a job

Jobs that need this type show a credential dropdown (for example **FTP Server Credentials** or **Credential**). You can also use **Add New … Credential** from some job forms.
