# EZE Analytics Interface

Client credentials for the EZE Analytics REST API.

| | |
| --- | --- |
| **Group** | Finance |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | EZE Analytics API to File |

## How it works

1. Enter REST API URL, Client ID, and Client Secret.
2. Select on EZE Analytics API to File.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **REST API URL** | Base URL of the EZE Analytics REST API for your environment. |
| **Client ID** | OAuth / API client identifier issued for your EZE Analytics integration. |
| **Client Secret** | Secret paired with the client ID. Write-only after save. |

## In a job

On **EZE Analytics API to File**, pick this credential for API auth. You can also use **Add New … Credential** from some job forms when available.
