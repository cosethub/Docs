# EZE Analytics Interface

Client credentials for the EZE Analytics REST API.

| | |
| --- | --- |
| **Group** | Finance |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | EZE Analytics API to File |

## How it works

1. Enter REST API URL, Client ID, and Client Secret.
2. Select on EZE Analytics API to File.

## Connection Settings fields

- **REST API URL**
- **Client ID**
- **Client Secret**

## In a job

Jobs that need this type show a credential dropdown (for example **FTP Server Credentials** or **Credential**). You can also use **Add New … Credential** from some job forms.
