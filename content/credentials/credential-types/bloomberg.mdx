# Bloomberg

Bloomberg API service host settings for Bloomberg file jobs.

| | |
| --- | --- |
| **Group** | Finance |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Bloomberg to File, Bloomberg Historical to File, Custom Bloomberg to File |

## How it works

1. Enter Server Host and Server Port.
2. Select as Bloomberg Account on Bloomberg jobs.

## Connection Settings fields

- **Server Host**
- **Server Port**

## In a job

Jobs that need this type show a credential dropdown (for example **FTP Server Credentials** or **Credential**). You can also use **Add New … Credential** from some job forms.
