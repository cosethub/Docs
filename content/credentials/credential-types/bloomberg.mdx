# Bloomberg

Bloomberg API service host settings for Bloomberg file jobs.

| | |
| --- | --- |
| **Group** | Finance |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Bloomberg to File, Bloomberg Historical to File, Custom Bloomberg to File |

## How it works

1. Enter Server Host and Server Port.
2. Select as Bloomberg Account on Bloomberg jobs.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Server Host** | Hostname or IP of the Bloomberg API process (Server API / Desktop API gateway). Often `localhost` when BBComm runs on the Bridge. |
| **Server Port** | TCP port the Bloomberg API listens on. Default for BLPAPI is typically `8194`. |

## In a job

On Bloomberg jobs, pick this credential as the Bloomberg account. You can also use **Add New … Credential** from some job forms when available.
