# Google OAuth

OAuth login for Google mail accounts used by Email and Email Check.

| | |
| --- | --- |
| **Group** | Email |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Email, Email Check |

## How it works

1. Choose Google OAuth and complete Login to grant access.
2. Tokens are stored on the credential.
3. Refresh when access expires.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Login** | Starts the Google consent flow. Complete it in the browser so CoSet can store tokens for this mailbox. |
| **Token Type** | OAuth token type returned by Google (typically `Bearer`). Usually filled after Login. |
| **Scope** | OAuth scopes granted (mail send/read as configured). Filled after Login. |
| **Access Token** | Short-lived Google access token. Populated by Login / refresh — do not paste manually in normal use. |
| **Refresh Token** | Long-lived refresh token used to obtain new access tokens. Populated by Login. |

## In a job

On **Email** / **Email Check**, pick this OAuth credential instead of IMAP/SMTP password auth. You can also use **Add New … Credential** from some job forms when available.
