# SQL Server

SQL Server connection for jobs and data warehouses.

> Table to CSV uses a warehouse that is already bound to SQL/PostgreSQL credentials — not a direct credential picker on that job.

| | |
| --- | --- |
| **Group** | Database |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | SQL Text/Procedure, SQL Bulk Load, Data warehouses (staging/warehouse accounts), Many finance jobs that need a SQL account |

## How it works

1. Choose Connection String or Server Details.
2. Optionally mark Cloud accessible connection for cloud-reachable databases.
3. Attach to warehouses and/or pick in SQL jobs.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Credential Format** | How you supply connection details: **Connection String** or discrete **Server Details** fields. |
| **Cloud accessible connection** | When on, marks the database as reachable from cloud / off-network Bridges. |
| **Connection String** | ADO.NET / SQL Server connection string when Credential Format is Connection String. |
| **Server Name** | SQL Server host or instance (`host` or `host\\INSTANCE`). |
| **Authentication Type** | SQL authentication mode (for example SQL login vs Windows), as offered in the form. |
| **User Name** | SQL login or Windows user, matching Authentication Type. |
| **Password** | Password for that login. |
| **Database Name** | Initial catalog / database to open. |
| **Timeout (in seconds)** | Connection timeout for warehouse and SQL jobs using this credential. |
