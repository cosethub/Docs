# Amazon Identity Access Management

AWS access keys for automation and related cloud tasks.

| | |
| --- | --- |
| **Group** | Cloud |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | AWS Automation Job, Some data monitors |

## How it works

1. Enter Access Key Id, Secret Access Key, group, and region.
2. Select on AWS Automation Job.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Access Key Id** | AWS access key ID for the IAM user or programmatic principal (starts with `AKIA…` for long-lived keys). |
| **Secret Access Key** | Secret half of the access key pair. Store only here — never in job parameters. |
| **AWS Group Name** | Optional IAM group or logical grouping label used by your automation setup. |
| **AWS Region** | AWS region for API calls (for example `us-east-1`). Must match where the resources live. |

## In a job

Jobs that need this type show an AWS / IAM credential dropdown (for example on **AWS Automation Job**). You can also use **Add New … Credential** from some job forms when available.
