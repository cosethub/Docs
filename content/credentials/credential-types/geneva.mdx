# Geneva

Geneva application and related SSH settings for Geneva jobs and warehouse extracts.

| | |
| --- | --- |
| **Group** | Finance |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Geneva Loader, Geneva Query to File, Geneva RSL to File, Geneva Security Check, Ryan Datawarehouse, Related Geneva paths |

## How it works

1. Enter Geneva user, password, application server, and related service settings.
2. Add SSH details if your environment needs them.
3. Select on Geneva Loader, Query, RSL, Security Check, and warehouse jobs.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **User Name** | Geneva application login used by the Bridge for queries, loads, and RSL runs. |
| **Password** | Password for the Geneva user. |
| **Geneva Application Server** | Geneva application / session server host your environment connects to. |
| **Schema Revision** | Geneva portfolio schema revision / environment label your firm uses (must match the target Geneva environment). |
| **Configuration** | Named Geneva configuration / run profile for this connection. |
| **Timeout (in milliseconds)** | Client timeout for Geneva calls (milliseconds). Increase for long RSL or extract jobs. |
| **Service Manager Host** | Host running Geneva Service Manager when your deployment uses it for process control. |
| **Service Manager Port** | Port for Service Manager on that host. |
| **SSH User Name** | SSH login for the Geneva host when jobs need shell access (for example file drops or remote commands). |
| **Use Private Key File?** | When on, authenticate SSH with a private key instead of (or in addition to) password. |
| **SSH Password** | SSH password when not using key-only auth. |
| **Private Key File** | Path on the Bridge to the SSH private key file. |
| **License Count** | Number of Geneva licenses this integration may consume / reserve for concurrent work. |

## In a job

On Geneva Loader / Query / RSL / Security Check and related warehouse jobs, pick this Geneva credential. You can also use **Add New … Credential** from some job forms when available.
