# Geneva

Geneva application and related SSH settings for Geneva jobs and warehouse extracts.

| | |
| --- | --- |
| **Group** | Finance |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | Geneva Loader, Geneva Query to File, Geneva RSL to File, Geneva Security Check, Ryan Datawarehouse, Related Geneva paths |

## How it works

1. Enter Geneva user, password, application server, and related service settings.
2. Add SSH details if your environment needs them.
3. Select on Geneva Loader, Query, RSL, Security Check, and warehouse jobs.

## Connection Settings fields

- **User Name**
- **Password**
- **Geneva Application Server**
- **Schema Revision**
- **Configuration**
- **Timeout (in milliseconds)**
- **Service Manager Host**
- **Service Manager Port**
- **SSH User Name**
- **Use Private Key File?**
- **SSH Password**
- **Private Key File**
- **License Count**

## In a job

Jobs that need this type show a credential dropdown (for example **FTP Server Credentials** or **Credential**). You can also use **Add New … Credential** from some job forms.
