# HTTP/HTTPs

Username and password for HTTP or HTTPS downloads.

| | |
| --- | --- |
| **Group** | Web |
| **Where you create it** | Credential Hub → Create Credential |
| **Commonly used by** | HTTP/HTTPs Download |

## How it works

1. Enter username and password.
2. Select on HTTP/HTTPs Download.

## Connection Settings fields

| Field | Description |
| --- | --- |
| **Username** | HTTP Basic (or site) username for authenticated downloads. |
| **Password** | Password for that user. |

## In a job

On **HTTP/HTTPs Download**, pick this credential for authenticated GETs. You can also use **Add New … Credential** from some job forms when available.
