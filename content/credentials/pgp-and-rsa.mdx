# PGP and RSA keys

Encrypt and decrypt jobs do **not** pick a Credential Hub PGP type today. They point at **key files on disk** (and an optional password).

> Credential Hub still has PGP Public Key / Private Key / Key Pair type names in the system, but they are **disabled** and have no create form. Use file paths on the job instead.

## Decrypt File - PGP

On the job, set:

| Field | Purpose |
| --- | --- |
| **PGP Private Key Path** | Required path to the private key file |
| **PGP Public Key Path** | Optional |
| **Password** | Passphrase if the key needs one |

Then point the job at the encrypted source files and an output folder.

## Encrypt File - PGP

Use **PGP Public Key Path** (and related options on the job) so outbound files are encrypted before Email or FTP Transmit.

## RSA encrypt / decrypt

Same idea with file paths:

- **RSA Public Key Path**
- **RSA Private Key Path**

## Tips

- Store keys in a controlled folder on the bridge host; reference that path from the job.
- Keep passphrase secrets out of workflow names/descriptions.
- Chain: FTP Download / Email Check → **Decrypt File - PGP** → CSV load.
