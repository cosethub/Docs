# Getting started

Create a credential once, then select it from jobs (and warehouses) that need that connection.

## Open Credential Hub

1. Go to **Administration**.
2. Under **Security & Credentials**, open **Credential Hub**.
3. You see the list: name, type, description, last validated.

{/* SCREENSHOT: Credential Hub list */}

## Create a credential

1. Choose **Create Credential**.
2. Fill **Basic Information**:
   - **Credential Name** — clear name (`PB SFTP Prod`, `Ops IMAP`)
   - **Credential Type** — see [Credential types](./credential-types)
   - **Share Credential with Organization?** — on if others/jobs in the org should use it
   - **Set as Default Credential** — optional default for that type
   - **Credential Description**
3. Fill **Connection Settings** for the type (host, user, password, and so on).
4. Under **Validation & Permissions**, optionally turn on **Validate Credential**, set **Frequency** (Daily / Weekly), and a **Notification Group**.
5. Choose **Create** or **Create & Validate**.

## Edit, view, delete

| Action | Where |
| --- | --- |
| **View** | Open a row → Credential Details |
| **Edit** | Details → **Edit** → **Save** / **Save & Validate** |
| **Delete** | Details → **Delete** (needs permission; blocked if read-only) |

List status shows **Last validated: …** or **Not validated**.

## Use a credential in a job

1. Open a workflow job that needs a connection (for example FTP Download).
2. Find the credential field (for example **FTP Server Credentials**).
3. Pick your credential by name.
4. Or choose **Add New … Credential** to create one without leaving the job (still stored in Credential Hub).

Hint in many job forms: *Managed in Administration → Credential Hub.*

## Sharing and defaults

| Option | Meaning |
| --- | --- |
| **Share Credential with Organization?** | Other users/jobs in the org can select it |
| **Set as Default Credential** | Preferred default for that type in the org (one default per type) |
| **Groups and Permissions** | Extra permission levels on who can use/manage it |

Your own credentials and shared org credentials both appear in job pickers (for the matching type).

## Validation

For supported types, the bridge can periodically check that the login still works.

1. Enable **Validate Credential**.
2. Set **Frequency** to **Daily** or **Weekly**.
3. Optionally set a **Notification Group** for failures.
4. Or run **Create & Validate** / **Save & Validate** immediately.

## Tips

- Name credentials by **environment + purpose** (`Prod PB SFTP`, not `ftp1`).
- Prefer shared org credentials for production workflows.
- SQL for **Table to CSV** is usually attached on the **data warehouse**, not on the Table to CSV job itself — see [SQL for warehouse / Table to CSV](./examples/sql-warehouse).
- PGP/RSA encrypt and decrypt jobs use **key file paths**, not Hub PGP types — see [PGP and RSA keys](./pgp-and-rsa).
