# Credentials

**Credential Hub** is the secure place to store logins, connection strings, and API details. Workflows and warehouses pick credentials by name instead of embedding passwords in every job.

| Page | What you’ll learn |

## Where to find it

- **Administration** → **Security & Credentials** → **Credential Hub**
- Or **Your Credentials** from user settings (same hub)

## Big idea

```
Credential Hub          Workflow / Warehouse
─────────────────       ────────────────────
FTP/SFTP: PB SFTP  →    FTP Download → FTP Server Credentials
Email - IMAP: Ops  →    Email Check  → Credential
SQL Server: WH     →    Warehouse staging/warehouse account
                        (Table to CSV uses that warehouse)
```

## Before you begin

- You need **Credentials** permission (ReadWrite to create/edit).
- Prefer **Share Credential with Organization?** for accounts many workflows use.
- Use **Create & Validate** / **Save & Validate** when the type supports validation.
