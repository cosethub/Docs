# Warehouses

Warehouses hold structured data your workflows load and export — SQL Server, PostgreSQL, and related staging. In the product UI this area appears as **CoSet DB** (or **Warehouses / Databases**), with **Tables / Views** for browsing rows and **Views** for shaping datasets.

Use this section for day-to-day work on warehouse tables and views (monitoring, browsing). To build reusable query definitions, see [Views](/views).

## What you can do

| Topic | Description |
| --- | --- |
| [Data monitors](./data-monitors) | Alert on table or view rows when conditions match, optionally trigger a job |
