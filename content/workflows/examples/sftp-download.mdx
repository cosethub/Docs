# SFTP download

**Goal:** Wait for a file on SFTP, download it, then (optionally) decrypt and load it.

**FTP Download** supports FTP and **SFTP** through FTP/SFTP credentials in Credential Hub.

## Tree

```
Group: Prime Broker Cash File
 └── FTP Monitor           [schedule: weekdays 7:00]
      └── FTP Download     [On success]
           └── Decrypt File - PGP   [On success]   ← only if encrypted
                └── SQL Bulk Load   [On success]
      └── Email (alert)    [On failure]
```

Simpler version (no monitor): schedule **FTP Download** alone if the file is always there when you run.

## 1. FTP Monitor

Job type: [FTP Monitor](../job-types/ftp-monitor)

| Setting | Example |
| --- | --- |
| Credentials | SFTP prime-broker credential |
| Remote folder | `/outbound/cash` |
| File pattern | `CASH_*.csv` |
| Wait window | Until 9:00 or N minutes |

## 2. FTP Download (On success)

Job type: [FTP Download](../job-types/ftp-download)

| Section | What to set |
| --- | --- |
| **FTP Settings** | Same SFTP credentials |
| **Source Settings** | Remote folder + file name / pattern |
| **Destination Settings** | Local folder, for example `files/pb/cash` |

## 3. Optional next steps

| If the file is… | Next job |
| --- | --- |
| PGP encrypted | [Decrypt File - PGP](../job-types/decrypt-file-pgp) |
| Excel | [Convert Excel to CSV](../job-types/convert-excel-to-csv) |
| CSV ready to load | [SQL Bulk Load](../job-types/sql-bulk-load) |

## 4. Alert if the file never shows

[Email](../job-types/email) under FTP Monitor with **On failure**.

## What you practiced

- SFTP via **FTP Monitor** + **FTP Download**  
- Chaining decrypt / load only after a successful download  
- Failure alert when the remote file is missing
