# Encrypt File - PGP

Encrypt files with PGP before sending them out.

| | |
| --- | --- |
| **Category** | Systems and Security |
| **Where you pick it** | Step 1: Choose Your Job Type |

## How it works

1. Select source files.
2. Choose recipients/keys.
3. Often followed by FTP Transmit or Email.
