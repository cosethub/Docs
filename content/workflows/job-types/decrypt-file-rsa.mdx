# Decrypt File - RSA

Decrypt RSA-encrypted files.

| | |
| --- | --- |
| **Category** | Systems and Security |
| **Where you pick it** | Step 1: Choose Your Job Type |

## How it works

1. Select encrypted sources.
2. Provide RSA credentials.
3. Output decrypted files.
