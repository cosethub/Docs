# Unix Health Monitor

Check SSH server health (CPU, memory, disk, processes).

| | |
| --- | --- |
| **Category** | Systems and Security |
| **Where you pick it** | Step 1: Choose Your Job Type |

## How it works

1. Configure SSH credentials.
2. Set thresholds / checks.
3. Alert or branch on unhealthy results.
