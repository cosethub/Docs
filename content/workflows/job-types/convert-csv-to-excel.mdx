# Convert CSV to Excel

Convert CSV files to XLSX, optionally naming sheets.

| | |
| --- | --- |
| **Category** | Systems and Security |
| **Where you pick it** | Step 1: Choose Your Job Type |

## How it works

1. Select CSV source.
2. Set Excel destination.
3. Use before emailing a friendlier file.
