# Geneva Loader

Load data into Geneva for fund accounting or operations.

| | |
| --- | --- |
| **Category** | Finance and Accounting |
| **Where you pick it** | Step 1: Choose Your Job Type |

## How it works

1. Point at load files.
2. Configure Geneva settings.
3. Confirm load success before dependents.

## In a workflow tree

- Add as a child under a **Group** (or under another job).
- Give it a schedule, or **Run job based on parent status** (**On success** / **On failure** / **Always**).
- Add children for the next step after this job finishes.

See [Configure workflow trees](../workflow-trees) and [Examples](../examples).
