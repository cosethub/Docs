# FTP Download

Download one or more files from **FTP or SFTP** to a local destination.

> Use FTP/SFTP credentials from **Credential Hub**. Pair with [FTP Monitor](./ftp-monitor) when you must wait for the remote file to appear.

| | |
| --- | --- |
| **Category** | Email and Communication |
| **Where you pick it** | Step 1: Choose Your Job Type |

## How it works

1. **FTP Settings** — FTP/SFTP server credentials.
2. **Source Settings** — remote folder, file name / pattern, date naming if needed.
3. **Destination Settings** — local folder for the downloaded files.
