# Bloomberg Historical to File

Retrieve historical Bloomberg data for a date range and export to files.

| | |
| --- | --- |
| **Category** | Finance and Accounting |
| **Where you pick it** | Step 1: Choose Your Job Type |

## How it works

1. Set date range and securities.
2. Export historical series.
3. Use for backfills and analysis.

## In a workflow tree

- Add as a child under a **Group** (or under another job).

- Add children for the next step after this job finishes.
