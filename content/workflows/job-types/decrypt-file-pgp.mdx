# Decrypt File - PGP

Decrypt PGP-encrypted files so later jobs can read them.

> Common after Email Check or FTP Download of encrypted broker files.

| | |
| --- | --- |
| **Category** | Systems and Security |
| **Where you pick it** | Step 1: Choose Your Job Type |

## How it works

1. Select encrypted source files.
2. Provide PGP credentials/keys.
3. Write decrypted output to a folder.
