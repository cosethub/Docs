# Eze Analytics API to File

Retrieve EZE analytics via API and export to files.

| | |
| --- | --- |
| **Category** | Finance and Accounting |
| **Where you pick it** | Step 1: Choose Your Job Type |

## How it works

1. Configure EZE API access.
2. Export analytics files.
3. Distribute or load.
